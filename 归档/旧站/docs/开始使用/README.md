# 开始使用

先完成一条最短路径，再按业务需求扩展。你不需要从头读完全部文档，也不需要先学习底层 HTTP 协议。

## 第一次接触启澜

1. [认识启澜](产品介绍.md)：了解平台、业务后端和产品界面各自负责什么。
2. [跑通公开示例](../教程/README.md)：使用可下载的固定版本，完成第一轮对话并恢复历史。
3. [选择一项能力](../使用指南/README.md)：加入业务工具、知识或自定义卡片。

**只有公开制品时，选择 0.1.0 教程。** 教程前五步构成最小闭环；工具、知识和生产接入在之后继续。

## 接入已有系统

从[接入规划](../开发接入/接入流程.md)开始，先确认平台与双 SDK 版本，以及业务已有的登录方式。

- 已获得配套内部候选：阅读[SDK 接入步骤](../开发接入/SDK简化接入.md)，在原业务工程中声明能力、复用认证，再嵌入聊天界面。
- 只使用公开 0.1.0：沿用[固定版本教程](../教程/README.md)的 API 和构件，不套用候选示例。

后台查 [Java / Kotlin SDK](../开发接入/业务后台SDK.md)，前端查 [JS / TS SDK](../开发接入/前端SDK.md) 与[框架组件](../开发接入/React与Vue.md)。这些 SDK 参考描述内部候选，阅读时注意页首版本说明。

## 部署一套底座

从[部署与运维](../部署运维/README.md)选择 Docker 或独立 Jar 路线，再完成数据库、凭据、HTTPS 与 SSE 配置。平台已由团队部署时，业务开发者只需向管理员确认连接信息和应用授权，不必另起一套环境。

控制台用于授权与运行管理；需要操作说明时查[控制台手册](../使用指南/控制台/README.md)。

## 先选版本，再复制代码

| 路线 | 适合什么情况 | 从哪里开始 |
| --- | --- | --- |
| 公开固定版本 **0.1.0** | 需要公开下载、完整示例和可重复的入门路线 | [固定版本教程](../教程/README.md) |
| 内部开发候选 | 已由维护者提供配套平台与双 SDK，准备使用新接入 API | [候选接入步骤](../开发接入/SDK简化接入.md) |

当前后台候选为 `0.1.1-auth.20261023-6`；前端使用同轮候选 tgz，并需要配套支持 `business-auth/1.0` 的平台。**它们尚未公开发行，不能用公开 0.1.0 包替代。** 获取方式与协议版本的区别见[版本与获取](版本与获取.md)。

不确定下一页？查看[阅读地图](阅读地图.md)。原[快速开始](快速开始.md)入口也会引导到固定版本教程。
