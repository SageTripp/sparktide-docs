# 阅读地图

文档按工作顺序组织，而不是按内部模块组织：**理解产品 → 跑通示例 → 接入业务 → 深入使用 → 查参考**。找到你当前的位置即可开始。

## 一条完整的学习路线

| 阶段 | 阅读内容 | 读完后能做什么 |
| --- | --- | --- |
| 1. 理解产品 | [认识启澜](产品介绍.md) | 说清平台与双 SDK 的职责、业务系统保留的边界 |
| 2. 跑通示例 | [公开 0.1.0 教程](../教程/README.md)的第 1—5 步 | 发送消息、追问、刷新并恢复同一会话 |
| 3. 接入业务 | [接入规划](../开发接入/接入流程.md) → [候选接入步骤](../开发接入/SDK简化接入.md) | 在配套候选上接入原有登录、后台能力与聊天界面 |
| 4. 深入使用 | [能力指南](../使用指南/README.md) | 按需求增加工具、知识、卡片与运行治理 |
| 5. 上线与维护 | [部署与运维](../部署运维/README.md) | 检查持久化、网关、授权、备份和恢复 |

第 2、3 阶段是**不同版本路线**，不是把旧工程直接复制新 API 的升级步骤。跨版本时先核对[版本与获取](版本与获取.md)，成套更换平台和双 SDK。

## 应用接入

已经知道产品分工时，可以直接按技术栈阅读：

| 你正在做什么 | 优先阅读 |
| --- | --- |
| Java / Kotlin 后台集成 | [后台 SDK](../开发接入/业务后台SDK.md)与[接入步骤](../开发接入/SDK简化接入.md) |
| React / Vue 聊天界面 | [框架组件与状态层](../开发接入/React与Vue.md) |
| 无框架 JS / TS 客户端 | [前端 SDK](../开发接入/前端SDK.md) |
| 原有认证、租户与权限 | [接入规划](../开发接入/接入流程.md)与[后台身份配置](../开发接入/业务后台SDK.md#配置与身份) |
| 查询业务数据或调用操作 | [业务工具](../使用指南/业务工具.md)与[注解工具](../开发接入/业务接入/注解工具接入.md) |
| 接入内部资料或检索服务 | [知识库](../使用指南/知识库.md)与[知识路线](../开发接入/知识接入/README.md) |

SDK 管理的定义在控制台查看即可，不用重复创建；不要为接入主流程另写一套 SSE、身份或数据权限基础设施。

## 日常使用与运维

- **找一次失败的对话**：[监控与排障](../部署运维/监控与排障.md)，再按 Run 和调用链定位。
- **维护应用与授权**：[控制台手册](../使用指南/控制台/README.md)。
- **生产部署或升级**：[部署路线](../部署运维/README.md)与[升级备份](../部署运维/升级与备份.md)。
- **核对数据留存**：[审计查询、导出与留存](../开发接入/运维治理/审计查询导出与留存.md)。
