# 构建业务能力

已经跑通对话后，选择一项真正需要的能力。每次扩展都沿着同一条路径：**声明能力 → 检查依赖和权限 → 验证结果 → 发布到业务入口**。

如果还没有完成第一轮对话，请先走[公开示例](../教程/README.md)，或使用配套内部候选完成[业务接入](../开发接入/SDK简化接入.md)。

## 让助手理解任务

| 目标 | 入门 | 继续深入 |
| --- | --- | --- |
| 连接或更换模型 | [模型接入](模型接入.md) | [模型能力、路由与治理](../开发接入/模型治理/README.md) |
| 设定职责、工具范围和预算 | [智能体](智能体.md) | [父子智能体额度与结果](../开发接入/运行时/父子智能体额度与结果.md) |

先明确模型能力和助手允许执行的工作。配置候选模型不意味着可以自动重试带副作用的工具。

## 让助手使用业务数据

| 目标 | 入门 | 继续深入 |
| --- | --- | --- |
| 查询订单、设备或执行业务操作 | [业务工具](业务工具.md) | [Java / Kotlin 注解工具](../开发接入/业务接入/注解工具接入.md) |
| 使用内部资料或已有检索服务 | [知识库](知识库.md) | [知识接入路线](../开发接入/知识接入/README.md) |
| 沿用登录、租户和数据权限 | [应用与权限](应用与权限.md) | [业务权限与可信上下文](../开发接入/业务接入/业务权限与可信上下文.md) |
| 管理文档授权与撤权 | [文档权限](文档权限.md) | [回答引用与鉴权来源预览](../开发接入/知识接入/回答引用与鉴权来源预览.md) |

从只读工具开始更容易核对结果。业务写操作仍需原服务负责授权、幂等和事务；接入知识也不等于绕过文档访问权限。

## 把结果交给用户

| 目标 | 阅读入口 |
| --- | --- |
| 展示流式消息、确认与取消 | [会话与运行](运行与审计.md) |
| 在对话中显示业务卡片 | [自定义 UI](界面组件.md) |
| 构建自己的聊天界面 | [React / Vue 组件与状态层](../开发接入/React与Vue.md) |
| 查询客户端方法和事件 | [前端 SDK](../开发接入/前端SDK.md)、[事件协议](../接口参考/事件协议.md) |

界面组件需要业务前端提供渲染器；不支持或渲染失败时应有文字回退。关闭界面不会自动撤销已经开始的业务执行。

## 扩展应用能力

基础能力验证后，再考虑子智能体、多模型策略、向量或混合检索。不要只看注册成功，还要核对实际依赖、模型能力、权限与运行结果。

发布前阅读[版本与发布](批次发布.md)，需要细节时查[声明式注册](../开发接入/业务接入/声明式注册与启动发布.md)和[批次预检](../开发接入/业务接入/批次预检与发布.md)。向量检索、组件渲染和外部回调需要部署环境或业务系统提供相应实现。

## 代码、控制台与参考各用在哪里

- **代码**：用后台 SDK 声明模型、智能体和业务能力，用前端 SDK 接入聊天。
- **控制台**：查看授权、资源与运行，按[操作手册](控制台/README.md)完成维护和诊断。
- **参考**：查 [SDK](../开发接入/README.md) 的方法与配置，或查 [HTTP API](../接口参考/README.md) 的请求、字段与错误。

专题中的 Registry JSON 用于解释契约或手工集成，不要求在控制台逐项照抄。公开固定版本与内部候选的 API 不可混用，具体支持状态见[能力状态](../产品支持/能力状态.md)。
