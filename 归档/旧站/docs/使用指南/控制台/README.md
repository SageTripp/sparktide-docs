# 控制台手册

SparkTide 控制台用于监控平台运行、处理告警和维护应用配置。业务工具、知识与智能体可通过 SDK 管理；控制台展示相同的资源与版本，并提供授权、排障和运维入口。

## 登录与权限

打开部署地址下的 `/console/index.html`，使用平台管理员或应用管理员凭据登录，默认进入总览。首次使用可在应用选择器旁创建应用；已有应用直接选择。

| 角色 | 可访问范围 |
| --- | --- |
| 平台管理员 | 平台健康、跨应用告警、共享模型授权、凭据及平台维护 |
| 应用管理员 | 已授权应用的运行记录、资源和应用运维 |
| 业务用户 | 通过业务客户端使用智能体；不使用管理控制台 |

访问凭据只保存在当前页面内存中，刷新或关闭页面后需重新登录。

| 任务 | 控制台入口 | 操作指南 |
| --- | --- | --- |
| 创建应用并完成 SDK 接入 | 应用选择器 → 创建应用 | [首次创建应用](多模块工作台.md#首次创建应用) |
| 查找应用、修改应用设置 | 应用管理 | [应用管理](多模块工作台.md#应用管理) |
| 查看应用状态与最近运行 | 总览 → 选择应用 | [日常监控](多模块工作台.md#日常监控) |
| 查询失败运行、查看调用链 | 选择应用 → 运行记录 | [运行查询与排障](多模块工作台.md#查询与排查运行) |

标题栏右侧的**帮助**提供当前任务的操作步骤、状态含义与排障建议，可以直接跳转至相关操作。

## 配置在何处维护

**SDK 管理**的资源由业务项目声明。修改定义后重新注册并发布版本，控制台用于查看、授权和运维。

**平台管理**的资源通过控制台维护。编辑草稿、检查依赖后发布；已发布版本保持不可变。

共享模型的应用授权、初始访问凭据由平台管理员配置。常规业务调用与配置可由相应权限的 SDK/API 完成，无需在控制台重复录入。
