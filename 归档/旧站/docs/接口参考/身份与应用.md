# 身份与应用

平台管理员创建应用、签发与撤销本地凭据；有效身份读取 /me，自身应用身份读取应用。默认入口由应用管理身份设置，并携带当前应用 revision。

字段类型见[数据结构](./数据结构.md)，通用身份和请求头见[API 入口](./README.md)。

## GET /v1/apps/{app}/agent-entries/{agentId}

### 参数

| 名称 | 位置 | 必填 | 类型与约束 |
| --- | --- | --- | --- |
| app | path | 是 | string；— |
| agentId | path | 是 | string；— |
| X-SparkTide-Business-Authentication | header | 否 | string；minLength: 1；maxLength: 24576；business-auth/1.0 私有 SDK 加密胶囊。与 Expires-At 和 Audience 三头同在或全无，不参与 chat 请求哈希；不得用于平台身份或用户 context。 |
| X-SparkTide-Business-Authentication-Expires-At | header | 否 | string；pattern: "^[0-9]{1,16}$"；加密胶囊到期的 Unix 毫秒时间。必须晚于现在且最多未来一小时；SDK 默认十分钟。 |
| X-SparkTide-Business-Authentication-Audience | header | 否 | string；minLength: 1；maxLength: 512；业务服务器配置的规范 HTTP(S) origin：小写 scheme/host，无路径、用户信息、query、fragment、默认端口。仅同 origin 且经过独立凭据认证的业务回调可收到材料。 |

### 响应

| HTTP | 响应类型 | 数据结构 |
| --- | --- | --- |
| 200 | application/json | [Ref](./数据结构.md#schema-ref) |
| 400 | application/json | [Error](./数据结构.md#schema-error) |
| 401 | application/json | [Error](./数据结构.md#schema-error) |
| 403 | application/json | [Error](./数据结构.md#schema-error) |
