# 前端核心

`@sparktide/frontend-sdk@0.2.0` 提供业务聊天客户端和三个框架的状态适配。包是 `private`。它依赖 `eventsource-parser@4.1.3`。Node 引擎是 `>=22 <23`。peer 为 React `>=18 <20`、Vue `^2.6.0 || ^3.5.0`，两者都可以不安装。根入口没有视觉组件和 CSS。

制品尚未发布到 npm registry。同版本 tarball 的取得方式见 接入总览（配套文档：/0.2.0/开发接入/接入总览.md）。无界面用法的源码在 `examples/0.2.0/core-client`。

## 安装

::: code-group

```sh [npm]
npm install ./vendor/sparktide-frontend-sdk-0.2.0.tgz
```

```sh [pnpm]
pnpm add ./vendor/sparktide-frontend-sdk-0.2.0.tgz
```

```sh [Yarn]
yarn add ./vendor/sparktide-frontend-sdk-0.2.0.tgz
```

:::

文件名以维护者实际打出来的包为准。上面三条是本地文件安装写法，不是公网 registry 已经成功的记录。

## 入口

| 导入 | 导出 | 不含 |
| --- | --- | --- |
| `@sparktide/frontend-sdk` | `createClient`、`SparkTideError`、`ConversationMetadataError`、`defineAiComponent`、`s` | 视觉组件、CSS |
| `@sparktide/frontend-sdk/react` | `SparkTideProvider`、`useChat`、`useChatComponents` | 视觉 |
| `@sparktide/frontend-sdk/vue` | Vue 3 的 `SparkTidePlugin`、`useChat`、`useChatComponents` | Vue 2 运行时 |
| `@sparktide/frontend-sdk/vue2` | `SparkTidePlugin`、`createChatMixin`、`ChatMixinState` | Vue 3 运行时 |
| `@sparktide/frontend-sdk/platform` | 受控运维客户端 | 业务聊天 |

`createClient` 的 `baseUrl` 是业务聊天前缀，例如 `/api/ai`。`auth` 省略时按当前源 Cookie 处理。`timeoutMs` 默认 30000，只管普通请求。`traceparent` 只关联诊断。

| `auth.type` | 必填 | 默认 |
| --- | --- | --- |
| `cookie` | 无 | `csrfHeader` 为 `X-CSRF-TOKEN`。`credentials` 为 `same-origin` |
| `bearer` | `token()` | `credentials` 为 `omit`。空白或含换行的 token 在本地拒绝 |
| `headers` | `headers()` | `credentials` 为 `omit` |

`identityKey()` 是本地隔离用的非秘密字符串。变化会 `reset()`。注销返回 `null` 后，后续请求以 401 拒绝。它不发到服务端。

`AiClient.chat.run` 返回任务句柄，不自动订阅。`task.cancel()` 才请求取消后台运行。`createChat` 给无框架页面。`registerComponents` 超过 64 个或标识重复会抛错，并且不改已有注册。`dispose` 之后任何调用抛出 `CLIENT_DISPOSED`。

`SparkTideError` 在本地失败时 `status === 0`，例如 `CLIENT_RESET`、`CLIENT_DISPOSED`、`CLIENT_AUTH_INVALID`。`retryable` 不触发自动重发。

## 最小示例

::: code-group

```ts [TypeScript]
import {createClient} from '@sparktide/frontend-sdk';

export const ai = createClient({
  baseUrl: '/api/ai',
  auth: {
    type: 'bearer',
    token: () => loginStore.token,
    identityKey: () => loginStore.sessionRevision,
  },
});
```

```js [JavaScript]
import {createClient} from '@sparktide/frontend-sdk';

```
