# 模型声明

`dev.sparktide:sdk-model-spi:0.2.0` 提供 `@AiProvider`、`@AiModel`、`@Agent` 和能力枚举 `Support`。字节码目标是 Java 8。`sdk-java` 与 `sdk-java8` 都传递它，所以使用 Starter 的应用不用再声明这一坐标。只有在不引入核心、又要编译这些注解时才直接依赖。

制品尚未发布到 Maven Central。直接依赖它不能发起模型调用。调用还需要一个 `sdk-model-*` 适配器和核心或 Starter。传输上限见 [模型 HTTP 传输](模型HTTP传输.md)。各供应商特有选项见对应章节。

## 占位符与继承

使用默认 `ModelEnvironment.system()` 时，`baseUrl`、`endpoint`、`apiKey` 若包含 `${`，整段必须是一个 `${NAME}`。`NAME` 为字母或下划线开头，其余只能是字母、数字、下划线。不能写默认值，不能写成 `https://${HOST}/v1`。地址在绑定时解析；密钥在每次实际调用时解析。对应阶段解析失败或变量缺失会拒绝，占位符原文不会发给供应商。不含 `${` 的值按字面地址或字面密钥使用。`apiKey` 的字面会进入 class 文件，密钥请使用占位符、`apiKeyEnv` 或 `apiKey()`。

Spring Starter 使用 Spring 的 `Environment.resolveRequiredPlaceholders`，可读取宿主属性并遵循 Spring 的占位符规则，包括带点的属性名、嵌入式表达和默认值。上述整段 `${NAME}` 限制仅针对默认系统环境解析器；自定义 `ModelEnvironment` 以其实现为准。

`model` 不是占位符。`apiKeyEnv` 写的是变量名本身，不是 `${...}`。

同一注解里只能留下 `baseUrl` 与 `endpoint` 中的一个，也只能留下 `apiKey` 与 `apiKeyEnv` 中的一个。子类未写的项继承父类。子类写了 `baseUrl` 会清掉父类的 `endpoint`，写了 `endpoint` 会清掉父类的 `baseUrl`。子类写了某一种密钥来源，会清掉父类的另一种。

`apiKey()` 在 Provider 上返回 `Supplier`。它和注解密钥合计只能留一种。方法写在子类、注解写在父类时用方法；注解写在子类、方法写在父类时用注解。同一个类上两种都写会拒绝。`Supplier` 在每次实际调用时才执行。

要求 HTTP 的适配器必须最终得到 `baseUrl`、`endpoint` 或该适配器自己的默认根。地址须为 `http` 或 `https`，有主机，且不能带用户信息、查询串或片段。这些官方模型适配器都要求 HTTP。

## @AiProvider

注解加在 Provider 类上，供多个模型复用。密钥不进入注册图或诊断。

| 参数 | 默认 | 范围 | 含义 | 何时用 |
| --- | --- | --- | --- | --- |
| `baseUrl` | 空 | 空，或字面协议根，或整段 `${NAME}` | 协议根。适配器再拼接自己的路径 | 覆盖官方默认根，或该提供器没有默认根时 |
| `endpoint` | 空 | 同上，且与 `baseUrl` 互斥 | 完整请求地址，原样使用，不再拼接路径 | 网关路径不符合该适配器的拼接规则时 |
| `apiKey` | 空 | 空，或整段 `${NAME}`。字面密钥会进 class 文件 | 调用时解析的供应商密钥 | 密钥放在宿主配置时 |
| `apiKeyEnv` | 空 | 空，或 `[A-Za-z_][A-Za-z0-9_]{0,127}`，且与 `apiKey` 互斥 | 环境变量名 | 密钥只存在于环境变量时 |
| `apiKey()` | 返回 null | 与上面两种注解来源合计只留一种 | 每次调用读取密钥的 `Supplier` | 密钥要轮换，或来自自有密钥服务时 |

## @AiModel

注解加在模型类上。连接和密钥仍然只写在 Provider 上。

| 参数 | 默认 | 范围 | 含义 | 何时用 |
| --- | --- | --- | --- | --- |
| `model` | 必填 | 非空白，最长 128。不解析 `${}`，不推断能力 | 供应商模型标识 | 每个模型类。换成该环境已经核对过的真实标识 |
| `name` | 空 | 空则由简单类名转成小写连字符名。最终须匹配 `[a-z][a-z0-9-]{0,63}` | 平台资源名 | 想要稳定名字，或类名转换结果不合法时 |
| `provider` | `DefaultModelProvider` | 一个 Provider 类 | 使用哪个配置类上的地址、密钥和 `options()` | 配置写在子类上时必须指向该子类。省略时用模型父类自带的官方提供器，不会自动选中外层子类 |
| `toolCalling` | `UNKNOWN` | `UNKNOWN`、`SUPPORTED`、`UNSUPPORTED` | 工具调用能力声明 | 该环境核对之后再改。`UNKNOWN` 不能当成已支持 |
| `streaming` | `UNKNOWN` | 同上 | 流式能力声明 | 同上 |
| `structuredOutput` | `UNKNOWN` | 同上 | 结构化输出声明 | 同上 |
| `contextWindow` | 0 | 0 到 10000000。大于 0 时，`maxOutputTokens` 不能超过它 | 上下文窗口声明。0 表示未知，不写入能力 | 只填写本环境核对后的真实值 |
| `maxOutputTokens` | 0 | 0 到 10000000，且不能超过已填写的窗口。经 `@Agent` 写入运行配置时，`ModelProfile` 只接受 1 到 32768 | 输出上限声明。0 表示未知，不写入运行配置 | 智能体要限制回答长度时，写 1 到 32768 内的业务上限 |

`@AiModel` 没有视觉、音频、温度、`topP`、`seed` 或价格字段。温度等生成项即使出现在 `ModelProfile` 构建器里，`@Agent` 编译也不会从本注解写入。适配器是否转发它们，见对应供应商页。未写入输出上限时，SDK 的智能体编译说明会把运行回落到平台默认的 1024。这不是厂商规格。

模型父类里的 `provider()` 对官方嵌套 `Model` 是最终方法，不能改写。Java 静态嵌套类也不会自动绑到外层 Provider。自定义了 `@AiProvider`、`options()`、`httpOptions()` 或 `apiKey()` 时，`provider` 必须写成那个子类。

没有注册成 Spring Bean 的模型类和 Provider 类都要有公开无参构造。

## @Agent

注解加在智能体声明类上。它只声明能力，不授予用户数据权限，扫描时不访问模型服务。

| 参数 | 默认 | 范围 | 含义 | 何时用 |
| --- | --- | --- | --- | --- |
| `name` | 必填 | `[a-z][a-z0-9-]{0,63}`，应用内不重复 | 稳定智能体标识 | 每个入口 |
| `instructions` | 必填 | 非空白，最长 16384 个字符；或以 `classpath:` 开头 | 系统提示词，或 UTF-8 资源路径 | 用正文，或把长提示词放进资源 |
| `model` | 必填 | 至少一项，类型不重复。第一项是主模型，其余是显式候选。编译进运行配置时主模型加候选最多 8 个 | 模型声明类型 | 主模型必填。备用模型放在后面 |
| `tools` | 空数组 | Bean 类型。登记时该 Bean 须存在，且至少有一个 `@Tool` 方法 | 允许调用的工具 | 需要业务动作时 |
| `knowledge` | 空数组 | Bean 类型。登记时须有 `@Knowledge` 方法 | 允许调用的知识 | 需要按当前用户检索时。空数组表示不启用 |
| `delegates` | 空数组 | 其他 `@Agent` 类型。不能成环，编译深度不超过 8 | 允许委派的智能体 | 要把一部分工作交给另一个声明时 |
| `defaultAgent` | false | 同一应用最多一个 true。只有一个入口且都没写时，编译会把该入口当作默认 | 是否为应用默认入口 | 用户未指定智能体时的入口 |
| `permissions` | 空数组 | 最多 64 个，不重复。每项匹配 `[a-zA-Z][a-zA-Z0-9_.:-]{0,127}` | 业务入口所要求的权限标识 | 声明入口权限要求；实际业务数据权限仍由原服务判断 |
| `autoSelectUi` | false | true 时必须已经有界面目录 | 是否选用自动导入目录中的全部组件 | 值班台要开放已导入组件时 |
| `commonComponents` | true | false 不加入内置通用组件目录，不放宽工具或入口权限 | 是否将内置通用组件目录加入该智能体的允许使用范围 | 前端仍需注册同版本渲染组件；不使用内置目录时写 false |
| `maxSteps` | 8 | `-1`，或 `1..32`。0 和其他值会拒绝 | 单次运行的模型尝试次数。`-1` 表示不限制，平台须接受同一合同 | 要收紧或明确不限制尝试时 |
| `maxToolCalls` | 8 | `-1`、0 或 `1..64` | 单次智能体调用的工具次数。`-1` 不限，0 禁用 | 交接班只整理文字时写 0；要防止反复重启时写一个小上限 |
| `timeoutSeconds` | 60 | 1 到 600，单位秒 | 单次运行期限 | 手册检索和工具来回需要更长时间时 |
| `maxBudgetUnits` | 32000 | 256 到 1000000 | 序列化输入、工具描述和输出的字符预算，不是供应商 Token，也不是价格 | 同时带通用界面、业务界面和工具结果时，可写 150000。步骤、工具次数和超时仍然生效 |

`classpath:` 后面的路径去掉可选的前导 `/`，不能含 `..`。资源最大 65536 字节，按 UTF-8 解码，解码后的正文仍须不超过 16384 个字符。登记时资源必须存在。

`@Agent` 没有供应商 Token 预算、费用上限、温度或采样字段。

## Support

`UNKNOWN` 表示尚未声明或尚未验证，依赖该能力的发布不能据此通过。`SUPPORTED` 表示业务声明支持，适配器和供应商行为仍需验证。`UNSUPPORTED` 表示明确不支持，依赖该能力时应拒绝调用。`UNKNOWN` 不等于 `SUPPORTED`。

下面示例里的 `SUPPORTED`、窗口和输出上限都是值班示例自己的演示声明，用来占用这些字段。它们不是厂商公布的能力表或价格。`example-chat-model` 与 `example-fallback-model` 要换成该宿主已经核对、账号里实际存在的模型标识。

```java [Java]
import dev.sparktide.sdk.annotation.Agent;
import dev.sparktide.sdk.annotation.AiModel;
import dev.sparktide.sdk.annotation.AiProvider;
import dev.sparktide.sdk.annotation.Support;
import dev.sparktide.sdk.provider.OpenAICompatibleProvider;

/**
 * 值班知识助手的兼容网关。
 * baseUrl 是协议根，适配器会再拼接 /chat/completions。
 * 本例使用整段 ${NAME}，可同时兼容默认系统解析器和 Spring 宿主。
 */
@AiProvider(baseUrl = "${OPS_MODEL_BASE_URL}", apiKey = "${OPS_MODEL_API_KEY}")
public class OpsGateway extends OpenAICompatibleProvider {}

/**
 * 主模型。provider 必须指向带配置的子类；
 * 只继承 OpsGateway.Model 并不会用上 OpsGateway 的地址和密钥。
 */
@AiModel(
    // 平台资源名。空着会由类名变成 ops-knowledge-model，规则与这里相同。
    name = "ops-knowledge-model",
    // 供应商模型标识。换成已核对的真实标识；这里的文字不会按占位符解析。
    model = "example-chat-model",
    provider = OpsGateway.class,
    // 演示声明：本环境核对过工具调用。未核对时保持 UNKNOWN。
    toolCalling = Support.SUPPORTED,
    // 演示声明：本环境核对过流式输出。
    streaming = Support.SUPPORTED,
    // 结构化输出还没核对，保持未知，不能写成已支持。
    structuredOutput = Support.UNKNOWN,
    // 演示窗口。0 表示未知。大于 0 时输出上限不能超过它，最大 10000000。
    contextWindow = 8192,
    // 演示输出上限。给智能体用时还要落在 1 到 32768。
    maxOutputTokens = 1024)
public class OpsKnowledgeModel extends OpsGateway.Model {
    /** 没有 Spring Bean 时，启动使用这个公开无参构造。 */
    public OpsKnowledgeModel() {}
}

/** 备用模型。演示声明为不能调用工具，窗口也单独填写。 */
@AiModel(
    name = "ops-fallback-model",
    model = "example-fallback-model",
    provider = OpsGateway.class,
    toolCalling = Support.UNSUPPORTED,
    streaming = Support.UNKNOWN,
    structuredOutput = Support.UNKNOWN,
    contextWindow = 4096,
    maxOutputTokens = 512)
public class OpsFallbackModel extends OpsGateway.Model {
    public OpsFallbackModel() {}
}

/** 交接班只整理已发生的处置，不再调用工具。 */
@Agent(
    name = "shift-handoff",
    instructions = "只根据本班已经记录的处置写交接。不要发起重启，也不要编造未发生的停机。",
    model = {OpsKnowledgeModel.class},
    defaultAgent = false,
    maxToolCalls = 0)
public class ShiftHandoff {}

@Agent(
    // 小写字母开头，可含数字和连字符，最长 64，应用内不重复。
    name = "ops-knowledge",
    // 直接写正文，最长 16384 个字符。资源路径见下一组。
    instructions = "仅依据用户提供的巡检记录归纳异常、已完成处置和待交接事项；缺少的信息标为待确认，不推测设备状态。",
    // 第一项是主模型，后面是显式候选。同一数组不能重复类型，主模型加候选最多 8 个。
    model = {OpsKnowledgeModel.class, OpsFallbackModel.class},
    tools = {}, // 本例只整理输入的记录，接入真实业务 Bean 后再填写类型。
    knowledge = {}, // 暂未接入业务知识服务。
    delegates = {ShiftHandoff.class},

    defaultAgent = true,
    // 声明入口权限要求，数据权限仍由原服务判断。最多 64 个。
    permissions = {"ops.equipment.read", "ops.runbook.read"},
    // 本助手不自动选用整个界面目录。打开时必须已经有目录。
    autoSelectUi = false,
    // 允许智能体使用内置通用组件目录；前端仍需注册相应渲染组件。
    commonComponents = true,
    // 默认 8。这里收紧到 6 次模型尝试，也可以写 -1 表示不限制。

    // 默认 8。本例无需业务工具；如启用工具，最多允许 4 次。

    // 默认 60 秒，允许 1 到 600。手册检索留 90 秒。

    // 默认 32000，允许 256 到 1000000。这是字符预算，不是供应商 Token 或价格。
```

## 调用时读取密钥

同一个类上不要再写 `apiKey` 或 `apiKeyEnv`。`Supplier` 每次模型调用才执行，适合轮换。返回空白会在该次调用被拒绝。

::: code-group

```java [Java]
package dev.example.ops.declaration.rotating;

import dev.sparktide.sdk.annotation.AiProvider;
import dev.sparktide.sdk.provider.OpenAICompatibleProvider;
import java.util.function.Supplier;

@AiProvider(baseUrl = "${OPS_MODEL_BASE_URL}")
public class OpsRotatingKey extends OpenAICompatibleProvider {
    @Override
    protected Supplier<String> apiKey() {
        return () -> {
```
