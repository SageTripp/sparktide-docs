# 整体组成

一次业务对话通常经过浏览器、业务后台和启澜平台三个部分。

```text
业务页面（React / Vue / Vue 2）
  └─ 前端 SDK：聊天状态、组件、流式展示
       └─ 业务后台：原有登录 + 后端 SDK + 业务服务
            ├─ 启澜平台：会话、执行、审批、预算、可靠存储
            └─ 模型 / 工具 / 知识回调：按配置提供能力
```

## 三个部分的职责

| 部分 | 负责 | 配置在哪里 |
| --- | --- | --- |
| 平台 | DSH 执行装配、可信身份、授权、PostgreSQL 事实与治理 | 部署环境、控制台 |
| 后端 SDK | 业务身份适配、模型与智能体声明、工具/知识回调、聊天网关 | 业务后台依赖、声明与部署配置 |
| 前端 SDK | 客户端、共享会话状态、消息与交互 | 业务前端 Provider/Plugin 与组件 |

浏览器调用业务后台，不持有平台管理密钥。`appId` 表示应用定位，普通 `context` 表示业务上下文，两者都不能提供授权。

## 运行环境

当前平台使用 Node.js / TypeScript、DSH、PostgreSQL 与 React 控制台。Java 17 用于可选独立文档解析器，不用于启动平台服务。业务后台仍可使用 Java/Kotlin；后端 SDK 提供不同运行时的适配模块。

默认平台地址是 `http://127.0.0.1:18092`，控制台位于 `/console/`。业务后台和前端地址由自己的应用配置决定。
