# 认识启澜

启澜把模型、业务工具和知识连接成可嵌入现有系统的智能体，并保存会话、运行、审批与调用事实。你可以沿用业务系统已有登录、租户和数据权限。

## 可以用来做什么

- **业务查询**：通过已授权工具读取业务数据，返回文本、表格或业务卡片。
- **知识问答**：查询托管文档或外部知识服务，展示回答引用和受控来源预览。
- **受控操作**：按工具声明执行业务操作，需要确认的操作由用户审批。
- **嵌入式助手**：在 React、Vue 3 或 Vue 2 应用内提供聊天、历史与交互界面。

## 平台负责什么

平台管理可信身份、权限、可靠存储、预算与运行治理。DSH 是唯一智能体执行循环；业务工具继续调用接入方的服务和权限规则。

## 使用前了解限制

当前以单活方式运行，PostgreSQL 保存可靠事实。增加副本不代表具备多实例执行协调。部分合同保留了未开放的入口，例如知识检索调试与知识评测；请以[能力与限制](../参考资料/能力与限制.md)为准。

平台生成的内容和工具执行结果应按实际业务用途核对；工具权限、外部模型可用性及业务数据正确性由对应接入环境共同决定。
