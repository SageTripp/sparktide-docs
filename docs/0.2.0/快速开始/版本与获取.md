# 版本与获取

本套文档统一使用 **0.2.0**。文档已按此版本整理；配套镜像、Maven 和 npm 制品尚未公开发行。

## 先检查手中的版本

| 组件 | 目标版本 | 检查位置 |
| --- | --- | --- |
| 启澜平台 | 0.2.0 | 平台根 `package.json` |
| 后端 SDK | 0.2.0 | `build.gradle.kts` 的默认 `sdkVersion`；实际制品 POM |
| 前端 SDK | 0.2.0 | `@sparktide/frontend-sdk` 的 `package.json` |
| UI 与 AI 组件包 | 0.2.0 | 对应包 `package.json` 与 SDK 依赖约束 |

构建时若人为覆盖版本，必须同时核对所有配套制品。不要因为协议版本为 1.0，就选择 0.1 的 SDK。

## 获取当前实现

平台与 SDK 的实现源码暂不公开。请向维护者获取同版本的平台包、镜像和 SDK 制品；文档与示例应用在文档仓库维护。没有收到对应制品时，不能直接假定公共仓库已存在 `0.2.0`，也不需要为了运行示例取得 SDK 源码。

- 平台部署见[部署准备](../部署运维/部署准备.md)；[独立进程部署](../部署运维/独立进程部署.md)中的源码构建步骤仅适用于已获授权的维护环境。
- 后端 SDK 制品选择与消费见[后端接入](../开发接入/后端接入.md)。
- 前端 SDK 和 UI 包安装见[前端接入](../开发接入/前端接入.md)。
- 组合示例见[完整示例](../开发接入/完整示例.md)。

旧站附带的 Jar、Maven 目录和入门 ZIP 已随旧文档归档，不能用于当前版本教程。

## 版本如何对应

文档 URL 含平台版本，每个版本都有独立的栏目、SDK 说明和机器合同下载。当前版本目录不会覆盖后续版本，后续新增版本也不应静默改写已发布旧版的说明。详见[版本与兼容性](../参考资料/版本与兼容性.md)。
