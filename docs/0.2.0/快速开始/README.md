# 快速开始

按下面顺序完成基础接入。已有运行环境的开发者可以从第 3 步开始。

| 步骤 | 阅读内容 | 完成标志 |
| --- | --- | --- |
| 1 | [认识启澜](认识启澜.md) | 确认适用场景与能力边界 |
| 2 | [整体组成](整体组成.md) | 知道平台、后台与前端分别负责什么 |
| 3 | [版本与获取](版本与获取.md) | 拿到版本匹配的源码或本地制品 |
| 4 | [运行第一个助手](运行第一个助手.md) | 完成发送、追问、刷新与历史检查 |

先建立基础聊天，再接入[业务工具](../能力指南/业务工具.md)和[知识问答](../能力指南/知识问答.md)。完整方法与配置在[参考资料](../参考资料/README.md)中查阅。
