# 事件协议

客户端需要区分运行终态、可靠事件与临时流式展示。使用前端 SDK 时，由 SDK 管理订阅、游标和状态恢复；自行实现客户端时需遵循本页与机器合同。

## 公共 AgentEvent

[下载本版本 AgentEvent Schema](/版本/0.2.0/agent-event.schema.json)。当前公共事件协议为 `1.0`；协议号与产品版本 `0.2.0` 含义不同。

| 事件组 | 示例 | 含义 |
| --- | --- | --- |
| 消息与运行 | `message.started`、`status.changed`、`message.completed` | 生命周期与结果 |
| 正文 | `text.delta` | 正文增量 |
| 模型、智能体、工具 | `model.started`、`agent.completed`、`tool.completed` | 各阶段事实，不等于整个任务成功 |
| 知识与引用 | `knowledge.retrieved`、`citation.created`、`citation.verified`、`reference.cited` | 检索来源、核验与实际引用 |
| 交互 | `ui.created`、`confirmation.required` | 组件或需要用户决定的操作 |
| 用量与错误 | `usage.updated`、`error` | 用量事实或执行错误 |

字段是否必填、可空和事件数据结构以 Schema 为准。事件中的 `runId` 用于关联运行；`traceId` 用于诊断，不是可靠日志。

## 原生流式预览

当前平台提供流式能力发现与运行原生流入口，具体路径和请求见[聊天与任务](HTTP接口/聊天与任务.md)。前端根据服务端能力消费流，不直接依赖 DSH 私有类型。

临时正文预览为减少等待时间而发送，不能推进可靠游标。终态、结构输出和可靠历史通过持久化屏障保存。连接中断后，只从已确认的可靠位置恢复；尚未保存的预览尾部可以丢失。

## 断线与取消

- SSE 断线后的重连是继续读取原任务，不是重新创建任务。
- 取消等待、组件卸载或关闭页面只停止本地观察；显式停止才向服务端发出取消请求。
- 恢复后按实际运行状态显示结果，不把 HTTP 202 当作完成。
- 认证失效时停止恢复旧身份内容；换用户后重新建立客户端状态。
- 不自动重发写操作。遇到未知结果时核对原请求、幂等键和回执。

完整客户端生命周期见[前端 SDK](前端SDK.md)，审批和跟进用法见[会话交互](../能力指南/会话交互.md)。
