# 基础界面

`@sparktide/ui-basic@0.2.0` 是基础聊天外观。peer 精确依赖 `@sparktide/frontend-sdk@0.2.0`。React peer 为 `>=18 <20`，React DOM 相同，Vue peer 为 `^2.6.0 || ^3.5.0`。三个 peer 都可省略；只用到哪个框架就安装哪个。包是 `private`，尚未发布到 npm registry。

根节点带 `data-st-library="basic"`。不要和 [大屏界面](./大屏界面.md) 的样式叠在同一个面板上。

## 安装

::: code-group

```sh [npm]
npm install ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-basic-0.2.0.tgz
```

```sh [pnpm]
pnpm add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-basic-0.2.0.tgz
```

```sh [Yarn]
yarn add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-basic-0.2.0.tgz
```

:::

这是本地 tarball 写法。公网安装未验证。使用前需要维护者先构建出 `dist`，否则包内转发文件没有目标。

## 导出

三个子路径 `@sparktide/ui-basic/react`、`/vue`、`/vue2` 导出同一组名字：`ChatPanel`、`Panel`、`ChatSurface`、`ConversationList`、`MessageList`、`ChatInput`、`ApprovalList`、`CitationPreview`、`ChatError`、`RunStatus`、`FollowUpList`、`SummaryPanel`、`ChatTheme`、`ThemePortal`。

样式必须显式导入 `@sparktide/ui-basic/style.css`。

| 属性 | 含义 | 何时用 |
| --- | --- | --- |
| `agent` | 已发布智能体名称，或 `{id, version}` | 指定入口。省略时由后台选择默认入口 |
| `client` | 已创建的 `AiClient` | 不用 Provider 时直接交给 `ChatPanel` |
| `label` | 可访问名称，默认「启澜」 | 页面上有多个区域时 |
| `appearance` | `native`、`light`、`dark` | 改明暗。`native` 用本库默认 |
| `density` | `comfortable` 或 `compact` | 收紧间距时 |
| `theme` | 语义变量，例如 `` `--st-primary` `` | 跟业务色板对齐 |

`ChatSurface` 以及列表类部件需要已经存在的状态和动作。`MessageList` 接收 `messages` 和 `onCitation`。`ChatInput` 接收 `chat`，或成对的 `state` / `actions`。

## 最小示例

状态适配来自核心包，视觉来自本包。三个框架的完整页面在 `examples/0.2.0/react-chat`、`vue3-chat`、`vue2-chat`。

::: code-group

```tsx [React]
import {SparkTideProvider} from '@sparktide/frontend-sdk/react';
import {ChatPanel} from '@sparktide/ui-basic/react';
import '@sparktide/ui-basic/style.css';

export function Assistant() {
  return (
    <SparkTideProvider client={ai}>
      <ChatPanel agent="main" />
    </SparkTideProvider>
  );
}
```

```ts [Vue 3]
import {createApp} from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue';
import {ChatPanel} from '@sparktide/ui-basic/vue';
import '@sparktide/ui-basic/style.css';

createApp(ChatPanel, {agent: 'main'})
  .use(SparkTidePlugin, {client: ai})
  .mount('#assistant');
```

```ts [Vue 2]
import Vue from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue2';
import {ChatPanel} from '@sparktide/ui-basic/vue2';
import '@sparktide/ui-basic/style.css';

Vue.use(SparkTidePlugin, {client: ai});
new Vue({
  render: h => h(ChatPanel, {props: {agent: 'main'}}),
}).$mount('#assistant');
```
