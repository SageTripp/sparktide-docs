# 文档合同

`dev.sparktide:sdk-document-spi:0.2.0` 是 PDF 等文件的合同，不是渲染器。字节码目标 Java 8。`sdk-java` 与 `sdk-java8` 都传递它，所以普通应用不用单独声明。要实现自己的 `DocumentRenderer`、又不使用内置 PDF 渲染时，才直接依赖这一坐标。生成 PDF 用 [PDF 文档](./PDF文档.md)。

制品尚未发布到 Maven Central。本模块依赖 `javax.validation:validation-api:2.0.1.Final` 做字段约束。

## 安装

::: code-group

```kotlin [Gradle Kotlin DSL]
dependencies {
    implementation("dev.sparktide:sdk-document-spi:0.2.0")
}
```

```xml [Maven]
<dependency>
  <groupId>dev.sparktide</groupId>
  <artifactId>sdk-document-spi</artifactId>
  <version>0.2.0</version>
</dependency>
```

:::

版本与核心相同。它不拉取 PDFBox。

## 关键类型

| 类型 | 含义 | 何时用 |
| --- | --- | --- |
| `DocumentReport` | 标题 1 到 120 字，章节 1 到 30 | 工具输入，由模型填写内容，不填写用户身份 |
| `DocumentOwner` | `appId`、`subjectId`、`tenantId`、`runId`、`callId` | 从 `ToolContext` 构造，不能来自模型参数 |
| `DocumentStorage.save` | 业务保存字节并返回 `DocumentArtifact` | 每个要落文件的应用都要实现 |
| `DocumentRenderer.render` | 只产生字节，不访问网络 | 自建格式时 |
| `DocumentGenerator` | 先渲染再交给存储，不自动重试 | 工具方法里调用 `generate` |
| `DocumentResult` | 只含保存成功后的 `artifact` 元数据 | 工具返回值。PDF 字节不进入模型 |

保存结果未知时不要再传一次。下载地址由业务自己鉴权。

## 最小示例

渲染器的可用实现见 [PDF 文档](./PDF文档.md)。只使用合同时，业务实现 `DocumentStorage`：

::: code-group

```java [Java]
public final class BusinessStorage implements DocumentStorage {
    public DocumentArtifact save(DocumentOwner owner, GeneratedDocument document) {
        String fileId = files.store(owner.getCallId(), document.bytes(), document.getFilename());
        return new DocumentArtifact(DocumentArtifactKind.FILE_ARTIFACT, fileId, document.getTitle(),
            document.getFilename(), document.getMime(), document.getSize(),
            "/files/" + fileId, "/files/" + fileId + "/preview");
    }
}
```

```kotlin [Kotlin]
class BusinessStorage(private val files: BusinessFiles) : DocumentStorage {
    override fun save(owner: DocumentOwner, document: GeneratedDocument): DocumentArtifact {
        val fileId = files.store(owner.callId, document.bytes(), document.filename)
        return DocumentArtifact(
            DocumentArtifactKind.FILE_ARTIFACT, fileId, document.title,
            document.filename, document.mime, document.size,
            "/files/$fileId", "/files/$fileId/preview")
    }
}
```

:::

上面的 `files.store` 是业务自己的存储，不是 SDK 方法。
