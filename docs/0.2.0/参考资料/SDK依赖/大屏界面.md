# 大屏界面

`@sparktide/ui-dashboard@0.2.0` 与基础界面导出同名部件，根节点是 `data-st-library="dashboard"`。peer 同样精确依赖 `@sparktide/frontend-sdk@0.2.0`，React 与 Vue 的可选 peer 范围也相同。包是 `private`，尚未发布到 npm registry。

一个聊天区域只选基础或大屏之一。组件名和属性与 [基础界面](./基础界面.md) 相同，差别是默认视觉和样式文件。

## 安装

::: code-group

```sh [npm]
npm install ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-dashboard-0.2.0.tgz
```

```sh [pnpm]
pnpm add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-dashboard-0.2.0.tgz
```

```sh [Yarn]
yarn add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ui-dashboard-0.2.0.tgz
```

:::

把基础包的导入从 `@sparktide/ui-basic` 换成 `@sparktide/ui-dashboard`，并改引 `@sparktide/ui-dashboard/style.css`。子路径仍是 `/react`、`/vue`、`/vue2`。公网安装未验证。

## 关键参数

属性表与基础界面相同：`agent`、`client`、`label`、`appearance`、`density`、`theme`。`appearance: 'native'` 使用大屏库自己的默认明暗，不是基础库的默认。主题变量仍然写在实例的 `theme` 上，不复制一整份布局。

本包不包含 `createClient`。客户端来自 [前端核心](./前端核心.md)。

## 最小示例

::: code-group

```tsx [React]
import {ChatPanel} from '@sparktide/ui-dashboard/react';
import '@sparktide/ui-dashboard/style.css';

export function DashboardAssistant() {
  return <ChatPanel client={ai} agent="main" appearance="dark" />;
}
```

```ts [Vue 3]
import {ChatPanel} from '@sparktide/ui-dashboard/vue';
import '@sparktide/ui-dashboard/style.css';

createApp(ChatPanel, {agent: 'main', client: ai}).mount('#assistant');
```

```ts [Vue 2]
import {ChatPanel} from '@sparktide/ui-dashboard/vue2';
import '@sparktide/ui-dashboard/style.css';

new Vue({
  render: h => h(ChatPanel, {props: {agent: 'main'}}),
}).$mount('#assistant');
```

:::

React 的对照文件在 `examples/0.2.0/react-chat/src/dashboard.tsx`。Vue 示例为了只加载一套样式，默认使用基础界面；把导入换成上面的包名即可。
