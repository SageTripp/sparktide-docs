# 通用展示组件

`@sparktide/ai-components@0.2.0` 提供四份 `3.0.0` 合同：`common.genui`、`common.genui-form`、`common.genui-question`、`common.genui-icons`。前三个默认注册，图标要写入 `include`。属性是对象 `spec`。`2.0.x` 合同只按精确版本渲染历史，不再绑定给模型。地图不在这个包里。

peer 精确依赖核心 `0.2.0`。React 与 Vue peer 可选，范围与核心相同。包是 `private`，尚未发布到 npm registry。后台 `@Agent` 的 `commonComponents` 默认为 true 时，这些合同才允许出现在该智能体的界面能力里。

## 安装

::: code-group

```sh [npm]
npm install ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ai-components-0.2.0.tgz
```

```sh [pnpm]
pnpm add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ai-components-0.2.0.tgz
```

```sh [Yarn]
yarn add ./vendor/sparktide-frontend-sdk-0.2.0.tgz ./vendor/sparktide-ai-components-0.2.0.tgz
```

:::

样式导入 `@sparktide/ai-components/style.css`。公网安装未验证。

## 关键参数

`registerComponents(CommonComponents, options)` 或 `createCommonComponents(options)`。

| 字段 | 取值 | 何时用 |
| --- | --- | --- |
| `include` | `genui`、`form`、`question`、`icons` | 默认前三个。需要图标时把 `icons` 列进去 |
| `exclude` | 同上 | 从默认集合去掉某一类 |
| `appearance` | `light`、`dark`、`auto` | 默认 `auto` |
| `locale` | `zh` 或 `en` | 默认中文 |
| `assetBase` | 引擎脚本目录，默认 `/genui-assets/` | 静态资源不在站点根时 |
| `onSubmit` | 收到调查答案 | 答案仍是用户输入，由后端按原权限处理 |

Vite 工程可以用 `@sparktide/ai-components/vite` 的 `genuiAssets()` 托管引擎文件。无框架页面用包根的 `mountCommonComponent`，卸载时调用返回的函数。包根还导出 `submissionMessage`。

## 最小示例

::: code-group

```tsx [React]
import {CommonComponents} from '@sparktide/ai-components/react';
import '@sparktide/ai-components/style.css';

ai.registerComponents(CommonComponents, {
  include: ['genui', 'form', 'question'],
  appearance: 'auto',
  locale: 'zh',
});
```

```ts [Vue 3]
import {CommonComponents} from '@sparktide/ai-components/vue';
import '@sparktide/ai-components/style.css';

ai.registerComponents(CommonComponents, {
  include: ['genui', 'form', 'question'],
});
```

```ts [Vue 2]
import {CommonComponents} from '@sparktide/ai-components/vue2';
import '@sparktide/ai-components/style.css';

ai.registerComponents(CommonComponents, {
  include: ['genui', 'question'],
});
```

:::

三个框架示例都注册了这组合同。业务自己的卡片仍用 `defineAiComponent`，不要把地图假装成这个包里的组件。
