# 版本与兼容性

平台、后端 SDK、前端 SDK 与配套 UI / AI 组件的本地版本统一为 **0.2.0**。当前文档描述 2026-10-31 的源码实现；平台与 SDK 制品尚未公开发行；文档网站发布不代表这些制品已经发行。

## 四类版本各自表示什么

| 版本 | 当前约定 | 用途 |
| --- | --- | --- |
| 产品与制品版本 | 0.2.0 | 平台、SDK 和配套组件的这一组实现 |
| 文档版本 | 0.2.0 | 对应这组实现的教程、参考和机器合同 |
| 公共协议版本 | 由合同定义，如 AgentEvent 1.0 | 消息格式兼容，不随制品编号机械修改 |
| 业务资源版本 | 应用发布时指定 | 智能体、模型、工具等不可变发布定义 |

第三方库版本不属于启澜制品版本。例如 Node、DSH、React、Vue 和 Gradle 保留各自依赖版本。数据库存储格式也独立维护，不能因产品号统一而改写。

## 运行时兼容

- 平台固定 Node `24.22.1` 与 npm `10.9.4`；使用平台自己的 `mise` 配置。
- 后端 SDK 按 Java 8 / Java 17、Boot 2 / Boot 4 选择对应模块；同包名核心只选一套。
- 前端 SDK 支持 React、Vue 3、Vue 2 的对应入口；构建工具与宿主运行依赖按该 SDK 配置选择。
- Java 17 文档解析器独立于 Node 平台，默认容器不包含解析器或 OCR。

具体安装见[后端接入](../开发接入/后端接入.md)、[前端接入](../开发接入/前端接入.md)、[部署准备](../部署运维/部署准备.md)。

## 使用与升级规则

1. 同一环境使用同一组 0.2.0 平台、SDK 和组件制品，并记录实际构建来源。
2. 不混入旧站 0.1.0 示例包或旧候选 API。
3. 发布资源前检查依赖、身份、模型和回调配置；升级平台前核对存储格式与恢复方案。
4. 版本号一致不代替联合验证：真实模型、业务登录、权限、长会话、背压与生产容量需在实际环境验收。

## 文档版本管理

每个启澜版本有独立 URL、栏目和机器下载。本站目前只提供 0.2.0。旧站以原始内容归档保存，未重新整理为可切换的历史版本。后续发布新版本时新增一套文档，已发布版本的安装方式和能力边界保持可追溯。
