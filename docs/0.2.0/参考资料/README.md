知道要做什么、需要查准确字段时，从这里进入。第一次接入请先看[开发接入](../开发接入/README.md)。

| [HTTP 接口](HTTP接口/README.md) | 平台与业务网关的参数、数据结构与机器下载 |
| [事件协议](事件协议.md) | 可靠事件、临时预览与恢复规则 |

| [错误与常见问题](错误与常见问题.md) | 常见失败的判断和恢复方式 |
| [公共错误码](公共错误码.md) | HTTP 状态、业务错误码、触发条件及处理建议 |
| [更新日志](更新日志.md) | 当前版本能力摘要、兼容性与发行状态 |
