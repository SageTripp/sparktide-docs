# 更新日志

记录启澜产品版本的能力、兼容性和发行状态。本文只收录当前维护的 **0.2.0**，不推测更早版本的变化。

## 0.2.0 · 开发中

文档核对日期：2026-10-31。平台、后端 SDK、前端 SDK 和配套组件的版本声明统一为 `0.2.0`；**尚未公开发布 0.2.0 制品**。以下是当前版本能力摘要，不是相对于某个未核验旧版的差异清单。

### 平台能力

| 领域 | 当前能力 | 详细说明 |
| --- | --- | --- |
| 智能体与模型 | 配置模型供应商、模型绑定和档案；发布智能体；记录模型调用、用量与诊断 | [模型](../能力指南/模型.md)、[智能体](../能力指南/智能体.md) |
| 业务连接 | 将业务服务接成工具，按权限调用；需要确认的操作经过审批 | [业务工具](../能力指南/业务工具.md) |
| 知识服务 | 内联、托管和远程知识接入；按文档权限检索、引用与预览 | [知识问答](../能力指南/知识问答.md) |
| 会话交互 | 流式回答、历史恢复、追问、停止、问卷、审批与会话管理 | [会话交互](../能力指南/会话交互.md) |
| 界面与成果 | 业务组件呈现，以及 PDF、表格等文件成果 | [界面与文件成果](../能力指南/界面与文件成果.md) |

### SDK 与文档

- 后端按 Java 8 / Java 17、Spring Boot 2 / 4 选择对应依赖；代码示例提供 Java / Kotlin 对照。
- 前端提供核心客户端、React、Vue 3、Vue 2 适配及对应组件；按依赖查询[前端 SDK 章节](前端SDK.md)。
- 每个产品版本使用独立文档目录和机器合同；语言与框架标签在页面之间保留选择。
- 示例应用随文档仓库维护，使用配套 SDK 制品；平台与 SDK 实现源码不属于公开示例。获取方式见[完整示例](../开发接入/完整示例.md)。

- 提供匹配 0.2.0 的[开发 Agent Skills](../开发接入/Agent技能.md)，覆盖后端、前端、模型配置与问题排查，并附离线参考。

### 兼容性与使用限制

- 平台运行时为 Node `24.22.1`、npm `10.9.4`，使用 PostgreSQL 保存可靠状态；当前按单活部署。
- 独立文档解析器使用 Java 17，默认平台容器不包含 Java 和 OCR。
- 公共协议号、资源版本、数据库格式与产品版本分别管理，不能因为统一为 `0.2.0` 就机械改写协议字段。
- 部分机器合同操作尚未开放。具体范围见[能力与限制](能力与限制.md)，升级前查看[版本与兼容性](版本与兼容性.md)和[升级与恢复](../部署运维/升级与恢复.md)。

正式发行后，本页再补充实际发布日期、获取入口和经验证的升级说明。
