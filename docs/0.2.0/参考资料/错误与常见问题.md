# 错误与常见问题

先区分认证失败、请求被拒绝、任务执行失败和结果未知，再选择恢复方式。不要把所有异常都归为登录过期，也不要用重新发送掩盖未知副作用。

## 常见 HTTP 状态

| 状态 | 优先检查 | 处理方式 |
| --- | --- | --- |
| 400 | 正文、字段、格式和前置条件 | 按合同修正，不无限重试 |
| 401 | 登录状态、令牌有效性、认证传递 | 恢复真实登录，再读取原状态 |
| 403 | 当前主体、应用/租户/功能/数据权限 | 核对权限来源，不更换 appId 绕过 |
| 404 | 资源、版本、所属主体和入口开放情况 | 核对路径与可见性；不直接认定数据被删除 |
| 409 / 412 | 幂等冲突、当前状态或 revision | 刷新原记录，确认冲突后再操作 |
| 429 | 应用配额、预算或限流 | 检查相应额度与恢复条件 |
| 503 | 外部服务、依赖或可选能力配置 | 查运行诊断；上传时核对解析器配置 |

具体错误码、触发条件和处理建议见[公共错误码](公共错误码.md)，各操作的错误说明见[HTTP 接口](HTTP接口/README.md)。应用应保留诊断信息，面向业务用户展示可理解的原因与下一步。

## 为什么接口受理成功却没有成功回答

受理响应与运行终态不同。查看 Run 的最终状态、错误和调用事实；模型请求可能失败，工具也可能拒绝授权。不要凭 HTTP 200/202 判断业务完成。

## 为什么关闭页面后任务还在运行

断开观察不会取消后台任务。需要停止时使用 SDK 或界面的显式取消动作；已经完成的外部操作不因取消而回滚。

## 为什么字段在接口文档中却调用不可用

机器合同包含预留操作。当前是否开放以[能力与限制](能力与限制.md)为准，尤其是知识调试、知识评测和部分管理入口。

## 为什么上传返回服务不可用

检查独立 Java 17 解析器是否完整配置。默认 Node 镜像不包含解析器，也不包含 OCR；相关配置见[环境变量](../部署运维/环境变量.md)。

## 为什么不能直接安装公开 0.2.0 包

当前配套制品尚未公开发行。使用维护者提供的配套本地包或从获授权源码构建，见[版本与获取](../快速开始/版本与获取.md)。

## 常见术语

| 名称 | 含义 |
| --- | --- |
| Agent / 智能体 | 包含职责、模型与允许能力的版本化定义 |
| Conversation / 会话 | 用户连续对话与公开历史 |
| Run / 运行 | 一次被受理的执行过程 |
| Context | 业务上下文数据，不是认证凭据 |
| Registry | 模型、工具、知识等版本化资源注册 |
| UNKNOWN | 结果或占用尚不能确认，不等于失败或零用量 |

更多排查步骤见[监控与排障](../部署运维/监控与排障.md)。
