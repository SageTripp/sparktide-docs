## 由本应用凭证所有者创建运行 {#post-v1-apps-app-chat}

`POST /v1/apps/{app}/chat`

用途：在指定应用下，由该凭证主体创建一次运行；由 Accept 选择 202 的 JSON 受理或 200 的 SSE 帧。身份：须为该应用的 USER 或 APP_ADMIN。PLATFORM_ADMIN 被拒绝，不能用平台管理身份发起或旁路业务正文。路径 app、模型以及可选业务认证、到期时间、受众参数都不是平台授权依据；运行归属该凭证的 subject 与 tenant。请求：路径 app 必填；可选 Idempotency-Key；必须提交 application/json 的 ChatRequest。响应：200 为 text/event-stream，事件标识为 runId:sequence，断流不取消运行；202 返回 JSON 的 Run，表示已受理。错误：403 表示平台管理身份或应用不在凭证范围内。流程：受理后用运行查询或事件回放继续跟踪；写操作不得自动重试，相同幂等键应按合同重放同一次受理而不是新开运行。

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| app | path | 是 | string；目标应用标识，仅用于确定作用域；不构成认证或授权依据。 |
| Idempotency-Key | header | 否 | string；同一写入意图的稳定幂等键；仅对声明支持的操作有效，同键异载荷会冲突。结果未知时使用原键核对，不换键重发。 |
| X-SparkTide-Business-Authentication | header | 否 | string；business-auth/1.0 私有 SDK 加密胶囊。与 Expires-At 和 Audience 三头同在或全无，不参与 chat 请求哈希；不得用于平台身份或用户 context。；minLength: 1；maxLength: 24576 |
| X-SparkTide-Business-Authentication-Expires-At | header | 否 | string；加密胶囊到期的 Unix 毫秒时间。必须晚于现在且最多未来一小时；SDK 默认十分钟。；pattern: "^[0-9]{1,16}$" |
| X-SparkTide-Business-Authentication-Audience | header | 否 | string；业务服务器配置的规范 HTTP(S) origin：小写 scheme/host，无路径、用户信息、query、fragment、默认端口。仅同 origin 且经过独立凭据认证的业务回调可收到材料。；minLength: 1；maxLength: 512 |

### 请求正文

Content-Type：`application/json`。正文必填。

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| protocolVersion | string | 是 | 聊天合同版本，固定为 1.0。；const: "1.0" |
| appId | string | 否 | 可选的应用标识。平台按凭证决定应用；业务网关若收到与配置不同的 appId，会直接拒绝。 |
| agentId | string / null | 否 | 指定本次运行使用的智能体。可以是 null，表示没有在请求里指定。 |
| agentVersion | string | 否 | 与 agentId 成对的精确版本。只写其中一个不能选择智能体。 |
| conversationId | string / null | 否 | 把这次运行接到已有会话。null 表示还没有指定会话。 |
| message | object | 是 | 用户本次发送的消息，只含 role 与 content。；additionalProperties: false |
| context | object | 否 | 业务上下文快照。它不是登录身份，也不能代替授权。；additionalProperties: true |
| client | object | 否 | 调用端环境。平台聊天请求可带平台标识和界面能力；业务网关只接受 uiCapabilities。；additionalProperties: false |

**message**

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| role | string | 是 | 这条用户消息的角色，合同固定为 user。不是令牌角色 USER 或 APP_ADMIN。；const: "user" |
| content | string | 是 | 用户输入的正文，长度 1 到 16384。；minLength: 1；maxLength: 16384 |

**client**

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| platform | string | 否 | 客户端自称的运行平台，只描述环境，不能当作可信身份。 |
| uiCapabilities | 数组：string | 否 | 客户端声明自己能展示的界面能力。服务端不会因此扩大权限。 |

用途：按游标回放调用方自己拥有的运行事件，用于断线后续读，而不是取消或重放副作用。身份：安全方案为 BearerAuth，摘要要求同一所有者。路径 app、runId、模型与用户 Context 不是授权依据；可选业务认证、到期时间、受众参数同样不能代替边界身份，管理身份没有业务正文旁路。请求：路径 app 与 runId 必填；可选 Last-Event-ID。响应：200 可返回 AgentEvent 数组或 text/event-stream。错误：合同声明 400、401、403、404、409、410、412、413、429、500、503 为 Error 信封，502 为上游失败。流程：用已见事件标识作为游标继续读取；SSE 断流不取消运行。本说明只解释协议用途，不表示该 Node 接口已经生产验收。

用途：将会话持久归档，请求体 ConversationArchivalRequest，200 返回 ConversationArchival，并设置 Cache-Control no-store，不缓存当前用户会话。不自动删除历史。身份：只允许会话所有者；BearerAuth 与业务认证、过期、受众。恢复或归档都不能绕过历史授权。app、模型、Context 不是身份，管理者无正文旁路。请求：路径 app、conversationId 与归档请求体。响应：200 表示状态已持久保存。相同状态重复调用保持原归档时间。错误：400、401、403、404、409、410、412、413、429、500、502、503；502 为上游失败。活动 Run 或 ACCEPTED 跟进阻塞归档。客户端不得自动重试，412 冲突须显式核对。流程：确认无活动 Run 与已受理跟进后提交，再用读取接口核对归档时间。重复归档不得刷新原归档时间，也不把归档理解成删除消息或跟进记录。  补充约束：只允许会话所有者；不自动删除历史。活动Run或ACCEPTED跟进阻塞归档；恢复不绕过历史授权。相同状态重复调用保持原归档时间；客户端不自动重试。

## 重新授权下载用户生成的PDF成果 {#get-v1-apps-app-runs-runid-artifacts-artifactid-content}

`GET /v1/apps/{app}/runs/{runId}/artifacts/{artifactId}/content`

用途：下载已经生成并保存的PDF文件。 身份：当前业务用户，平台重新核验运行所有者及业务和历史来源权限。 请求：GET路径包含runId与artifactId，不接收文件路径、外部URL或请求正文。 响应：200为application/pdf，附件下载，最多8MiB，no-store。 错误：401/403表示认证或权限拒绝，404表示不可见文件；503表示暂不可用，不自动生成或重放。 流程：用户明确要求报告，工具生成并保存，读取会话artifacts，再用此接口下载。

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| app | path | 是 | string；目标应用标识，仅用于确定作用域；不构成认证或授权依据。 |
| runId | path | 是 | string；生成文件的运行标识，不是授权依据。 |
| artifactId | path | 是 | string；文件成果标识，不是公开访问凭据。 |
| X-SparkTide-Business-Authentication | header | 否 | string；business-auth/1.0 私有 SDK 加密胶囊。与 Expires-At 和 Audience 三头同在或全无，不参与 chat 请求哈希；不得用于平台身份或用户 context。；minLength: 1；maxLength: 24576 |
| X-SparkTide-Business-Authentication-Expires-At | header | 否 | string；加密胶囊到期的 Unix 毫秒时间。必须晚于现在且最多未来一小时；SDK 默认十分钟。；pattern: "^[0-9]{1,16}$" |
| X-SparkTide-Business-Authentication-Audience | header | 否 | string；业务服务器配置的规范 HTTP(S) origin：小写 scheme/host，无路径、用户信息、query、fragment、默认端口。仅同 origin 且经过独立凭据认证的业务回调可收到材料。；minLength: 1；maxLength: 512 |
