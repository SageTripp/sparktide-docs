# 业务聊天接口


::: warning 合同与开放范围
本页是本版本随附机器合同的字段参考，合同包含预留操作，不代表每个接口都已开放。调用前先查[当前能力与限制](../能力与限制.md)。失败时请结合本页错误表与[公共错误码](../公共错误码.md)处理。
:::

这是业务后台 SDK 暴露的聊天网关合同。使用业务登录身份；路径基于业务后台配置的 HTTP 前缀，不把平台管理凭据交给浏览器。

[业务数据结构](业务数据结构.md) · [公共错误码](../公共错误码.md) · [开发接入](../../开发接入/HTTP接入.md)

## 业务后台标准聊天接口 {#post-chat}

`POST /chat`

用途：业务后台按标准聊天协议提交一次对话并获得 Run。请求体 ChatRequest，200 返回 Run。这是业务入口协议，未装配的 Node 接口只说明用途，不表示生产已验收。身份：businessBearer 或 businessCookie 二选一。Cookie 名由业务认证配置，必须使用业务 CSRF，SDK 可传 CSRF 头。会话、模型、Context、appId 都不是授权依据，管理者不能旁路业务正文。请求：可选 Idempotency-Key，长度 1 至 128，由 SDK 生成；提交结果不明时不得改用另一个幂等键重发。响应：200 为已创建或关联的 Run，受理不等于后续事件已结束。错误：default 拒绝或失败，继承底座错误码，写操作不得自动重试。流程：提交后用 Run 查询与事件流跟踪；SSE 断流不取消 Run。

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| Idempotency-Key | header | 否 | string；SDK 生成；提交不明时不得重发不同幂等键；minLength: 1；maxLength: 128 |

### 请求正文

Content-Type：`application/json`。正文必填。

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| protocolVersion | string | 是 | 聊天合同版本，固定为 1.0。；const: "1.0" |
| appId | string | 否 | 可选的应用标识。平台按凭证决定应用；业务网关若收到与配置不同的 appId，会直接拒绝。 |
| agentId | string / null | 否 | 指定本次运行使用的智能体。可以是 null，表示没有在请求里指定。 |
| agentVersion | string | 否 | 与 agentId 成对的精确版本。只写其中一个不能选择智能体。 |
| conversationId | string / null | 否 | 把这次运行接到已有会话。null 表示还没有指定会话。 |
| message | object | 是 | 用户本次发送的消息，只含 role 与 content。；additionalProperties: false |
| context | object | 否 | 业务上下文快照。它不是登录身份，也不能代替授权。；additionalProperties: true |
| client | object | 否 | 调用端环境。平台聊天请求可带平台标识和界面能力；业务网关只接受 uiCapabilities。；additionalProperties: false |

**message**

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| role | string | 是 | 这条用户消息的角色，合同固定为 user。不是令牌角色 USER 或 APP_ADMIN。；const: "user" |
| content | string | 是 | 用户输入的正文，长度 1 到 16384。；minLength: 1；maxLength: 16384 |

**client**

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| platform | string | 否 | 客户端自称的运行平台，只描述环境，不能当作可信身份。 |
| uiCapabilities | 数组：string | 否 | 客户端声明自己能展示的界面能力。服务端不会因此扩大权限。 |

### 响应

| HTTP | 说明 | 类型 |
| --- | --- | --- |
| 200 | 成功 | application/json：[Run](./数据结构.md#schema-run) |
| default | 拒绝或失败；继承底座错误码 | application/json：[Error](./业务数据结构.md#schema-error) |

### 错误

业务网关返回 `error.code` 与 `error.message`。平台错误的状态和代码会保留，消息经过脱敏。通用错误与运行失败详见[公共错误码](../公共错误码.md)。

| HTTP | error.code | 触发条件 | 处理 |
| --- | --- | --- | --- |
| 400 | `INVALID_REQUEST` | 业务网关在转发前拒绝未知字段、错误类型、不可读 JSON 或不符合该方法的协议版本。SdkHttpErrors 把 IllegalArgumentException 固定写成该码，消息为 Invalid chat request 或 SDK request could not be completed。 | 按业务合同改正文。不要把被拒绝的正文原样重放。 |
| 401 | `UNAUTHENTICATED` | 业务登录无法解析，或宿主认证异常被 SdkHttpErrors 认成未认证。平台上游的 401 会保留原 error.code。 | 恢复业务登录。网关不会用失败回执自动重放已经发出的写操作。 |
| 403 | `PERMISSION_DENIED` | 宿主授权被拒绝时，SdkHttpErrors 返回该码。平台上游的 403 保留原来的 error.code。 | 不要改用另一个应用的登录绕过。 |
| 503 | `UPSTREAM_UNAVAILABLE` | 控制器已关闭、流执行器或期限任务不可用，以及网关未分类异常。平台上游的其它状态和 error.code 原样透出，消息改为 SDK request could not be completed。 | 先读原运行或会话。不要把网关 503 当成平台已经执行失败。 |
| 400 | `INVALID_REQUEST` | 消息 role 必须是 user，protocolVersion 若出现则必须是 1.0，client 只接受 uiCapabilities。 | 按 ChatRequest 重写。幂等键可省略，省略时网关为本请求生成新键，不会自动重发。 |
| 403 | `PERMISSION_DENIED` | 正文 appId 不等于网关配置的应用时，控制器返回 Application outside scope。 | 不要在浏览器请求里指定其它应用。 |

平台 `PlatformException` 经过业务网关时保留 HTTP 状态和 error.code，消息固定为 “SDK request could not be completed”，不附带上游正文。网关没有为这些平台码再造一套状态。

## 创建业务会话 {#post-conversations}

`POST /conversations`

用途：按 ConversationCreate 创建一条业务会话，201 返回 Conversation。此为业务后台标准聊天协议的一部分，Node 未装配时身份：businessBearer，或名称由配置决定且必须带业务 CSRF 的 businessCookie。创建归属可信业务身份，不能用模型、Context 或 appId 充当授权，管理者没有业务正文旁路。请求：必填 JSON 正文，无额外路径参数。响应：201 表示会话已创建，后续读取仍受所有权约束且不应缓存为共享真源。错误：default 拒绝或失败并继承底座错误码。写操作不得自动重试；结果不明时由调用方显式核对是否已创建，而不是盲目再提交。流程：创建成功后使用返回标识读取或发起聊天。

## 分页列出当前用户的会话 {#get-conversations}

`GET /conversations`

用途：列出当前身份拥有的会话目录。身份：入口验证有效应用身份，按 appId、subjectId、tenantId 共同过滤所有者，不能用请求正文或 Context 替代身份。请求：limit、offset、archived 分页筛选，按 createdAt 倒序、相同时间按 id 倒序排列；更新会话不改变排序位置。响应：200 仅含会话 id、标题、创建及更新时间、消息数与归档时间，不含正文、摘要或业务查询结果。错误：认证和应用范围检查失败时拒绝。流程：目录不扫描历史业务资料权限；打开正文、运行和引用预览时在各自入口检查当前数据权限。历史业务权限变化不阻塞目录本身，所有者仍能看到其历史标题。

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| limit | query | 否 | integer；本页最多返回的记录数，范围和缺省值以参数Schema为准。；default: 20；minimum: 1；maximum: 200 |
| offset | query | 否 | integer；按当前排序跳过的记录数；不是可靠事件游标，不用于重放事件。；default: 0；minimum: 0；maximum: 1000000 |
| archived | query | 否 | boolean；仅接受单个true/false；默认未归档，true仅列已归档，不自动清理历史；default: false |

### 响应

| HTTP | 说明 | 类型 |
| --- | --- | --- |
| 200 | 成功 | application/json：[ConversationPage](./数据结构.md#schema-conversationpage) |
| default | 拒绝或失败；继承底座错误码 | application/json：[Error](./业务数据结构.md#schema-error) |

## 读取单条业务会话 {#get-conversations-id}

`GET /conversations/{id}`

用途：按标识读取一条业务会话，成功响应为 Conversation。只服务于已通过业务认证的调用方读取自己的会话，不生成摘要、不改归档、不触碰 Run。身份：businessBearer 或 businessCookie；Cookie 名由业务认证配置，必须使用业务 CSRF，SDK 可传 CSRF 头。路径 id、模型、Context、appId 都不是身份，管理者不能借管理身份读取业务正文。请求：路径 id，模式为 1 至 128 位字母数字及 _ . -。响应：200 为会话当前可见状态，涉及用户会话的读取按合同不缓存。错误：default 继承底座错误码，未见单独列出的状态码不要自行添加。流程：列表得到 id 后读取详情；若不存在或无权限，按继承错误处理并不自动重试写操作。未装配接口仅说明协议用途。 完整历史按游标渐进读取，不触发模型或历史工具。每页最多20条，nextBefore为null表示最早页；游标绑定会话当前分支，编辑后须重新读取第一页。累计messageCount不受页大小限制。

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| id | path | 是 | string；目标资源或记录的稳定标识，须属于当前授权作用域。；pattern: "^[a-zA-Z0-9_.-]{1,128}$" |
| limit | query | 否 | integer；本页最多消息条数；不限制会话总长度。；default: 20；minimum: 1；maximum: 20 |
| before | query | 否 | string；上一页返回的 nextBefore；省略读取最新页，编辑会话后旧游标返回409。；pattern: "^[a-f0-9]{16}:[1-9][0-9]{0,15}$" |

用途：持久归档业务会话，正文 ConversationArchivalRequest，200 返回 ConversationArchival，Cache-Control no-store，不缓存当前用户会话，也不自动删除历史。身份：只允许会话所有者；businessBearer 或带 CSRF 的 businessCookie，Cookie 名由配置决定。恢复不绕过历史授权，归档同样不能扩大权限。id、模型、Context、appId 不是身份，管理者无正文旁路。请求：路径 id 为 1 至 128 位字母数字及 _ . -，加必填正文。响应：200 表示状态已持久保存。相同状态重复调用保持原归档时间。活动 Run 或 ACCEPTED 跟进阻塞归档。错误：default 继承底座错误码。客户端不自动重试，冲突须显式核对。流程：确认无活动 Run 与已受理跟进后提交，再读取归档状态。  补充约束：只允许会话所有者；不自动删除历史。活动Run或ACCEPTED跟进阻塞归档；恢复不绕过历史授权。相同状态重复调用保持原归档时间；客户端不自动重试。
