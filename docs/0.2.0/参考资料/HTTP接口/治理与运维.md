## 读取最近二百条控制动作 {#get-v1-apps-app-audit}

`GET /v1/apps/{app}/audit`

用途：读取指定应用最近二百条控制动作，供应用管理员核对治理操作记录。身份：安全方案为 BearerAuth，摘要限定应用管理员；路径 app、模型与用户 Context 不是授权依据，管理身份没有业务正文旁路，本接口也不提供业务正文读取。请求：路径 app 必填，无请求体。响应：200 返回对象数组，合同未在本操作内展开元素字段，条数上限为最近二百条。错误：合同声明 400、401、403、404、409、410、412、413、429、500、503 为 Error 信封，502 为上游失败。流程：认证后只读查询；不修改审计记录，也不能把可丢跟踪当作可靠轨迹的替代。本说明只解释协议用途，不表示该 Node 接口已经生产验收。

| --- | --- | --- | --- |
| app | path | 是 | string；目标应用标识，仅用于确定作用域；不构成认证或授权依据。 |

## 分页查询应用运行记录 {#get-v1-apps-app-activity-runs}

`GET /v1/apps/{app}/activity/runs`

用途：在指定应用内分页查询运行活动，可按状态、完整运行标识和开始时间范围过滤，供运维或集成查看运行轨迹。身份：仅认 Bearer 所代表的可信身份；app 不是授权依据，管理身份没有业务正文旁路。请求：app 必填；limit 默认 50，范围 1 到 200；offset 默认 0，最大 1000000；status 可省略，省略表示全部，取值限于 QUEUED、RUNNING、WAITING_CONFIRMATION、SUCCEEDED、FAILED、CANCELLED、TIMED_OUT；runId 须完整精确匹配；from、to 为包含边界的 Unix 毫秒，to 不得早于 from。响应：200 返回 items 与 nextOffset，nextOffset 为空表示没有下一页。错误：失败走 default  Error 信封。流程：按页读取，不把 Trace 当可靠轨迹；失败不自动重试。协议用途说明，不表示生产已验收。

::: warning 当前未开放
当前 Node 平台尚未提供此操作。不要把合同字段或 SDK 方法的存在视为调用可用。
:::

### 请求参数

| 名称 | 位置 | 必填 | 类型与说明 |
| --- | --- | --- | --- |
| app | path | 是 | string；目标应用标识，仅用于确定作用域；不构成认证或授权依据。 |
| limit | query | 否 | integer；本页最多返回的记录数，范围和缺省值以参数Schema为准。；default: 50；minimum: 1；maximum: 200 |

用途：分页查询指定应用的配额预留，供管理员核对发送前登记的预留。原说明：需要应用管理员或平台管理员；写操作须 If-Match 当前 revision，记录原因与审计。预留在模型发送前与 SENT 原子登记。身份：应用管理员或平台管理员 Bearer；路径 app、模型与 Context 不是身份，管理身份没有业务正文旁路。请求：app 必填；limit 默认 50（1 到 100）；offset 默认 0，最大 1000000。响应：200 返回 QuotaReservationPage。错误：400为分页字段非法；401为认证失效；403为无目标应用管理权限；404为应用不存在；413表示本页人工证据超过4MiB，应减小limit后重新读取；503为可靠存储损坏或不可用。流程：只读分页；失败不自动重试。未知预留不得自动释放或自动重放。

用途：平台管理员查看脱敏策略是否启用、模式、适用范围以及字段和正则数量，不含完整规则正文。身份：BearerAuth，平台管理员；状态接口不返回业务正文，也不把 appId 或 Context 当身份。请求：无参数。响应：200 为 RedactionStatus，必含 revision、enabled、mode、appliesTo、fieldCount、patternCount。错误：合同列出的结构化响应包括400（请求字段或格式非法）；401（认证缺失或失效）；403（角色、作用域或当前业务权限不允许）；412（请求修订与当前记录不符，须只读核对后显式决定）。流程：用状态判断策略规模，需要规则明细时再读取完整策略。412 须停止并显式核对，不得自动重试。计数是观察值，不是可靠审计轨迹。未装配实现只按协议说明，不声称已生产验收。字段数与正则数只说明规模，规则文本仍须读取完整策略，试跑才看样例变化。
