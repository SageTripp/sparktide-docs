# 业务数据结构

由本版本机器合同生成。请求和响应字段若在文档映射里有单独的角色说明，表格采用该说明；折叠的 JSON 仍是合同原文。可选不等于允许 null；只有合同明确包含 null 时才能传入。

[HTTP 接口总览](README.md) · [公共错误码](../公共错误码.md)

## ConversationCreate {#schema-conversationcreate}



| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| title | string | 否 | 新建空会话时的标题。业务网关省略时按空字符串创建。；default: ""；maxLength: 128 |

::: details 完整定义

```json
{
  "type": "object",
  "additionalProperties": false,
  "properties": {
    "title": {
      "type": "string",
      "maxLength": 128,
      "default": "",
      "description": "知识文档、检索命中、知识条目或托管文档的标题文本，用于展示和识别，不是文档唯一标识。 最多字符数128；声明的缺省值见default，服务端是否补齐遵循操作规则。"
    }
  }
}
```

:::

        },

          "type": "string",

        }
      },

    }
  }
}

## ConversationSummaryContent {#schema-conversationsummarycontent}

单份持久化的展示摘要，按需读取，不触发模型调用。空摘要的 content、generatedAt、sourceHash 均为 null，messageCount 为 0，stale 为 false。生成范围最多包含最近 20 条成功消息及有界内部摘要；stale 表示与当前成功历史来源相比是否已过时。

| 字段 | 类型 | 必填 | 说明与约束 |
| --- | --- | --- | --- |
| protocolVersion | string | 是 | 聊天请求、Agent 事件、业务身份、权限回调或远端模型消息所声明的协议版本，标识报文遵循的合同版本。 在所属结构适用时为必填项；固定值："1.0"。；const: "1.0" |
| conversationId | string | 是 | 对话请求、运行、Agent 事件、后续跟进或会话摘要内容中的会话标识。对话请求可为 null，表示尚未指定会话。 在所属结构适用时为必填项。 |
| content | string / null | 是 | 对话消息、远端模型消息、知识条目或引用预览中的正文。远端消息在部分分支可为 null，表示没有正文。 在所属结构适用时为必填项；最少字符数1；最多字符数6000。；minLength: 1；maxLength: 6000 |
| generatedAt | integer / null | 是 | 生成时刻。运维状态表示这份状态何时生成；会话摘要可为 null，null 表示尚未生成，不是 0。 在所属结构适用时为必填项；最小值0。；minimum: 0 |
| sourceHash | string / null | 是 | 会话摘要所依据原文的摘要值。可为字符串；为 null 表示没有原文摘要，不能当成空串或零。 在所属结构适用时为必填项。；pattern: "^[a-f0-9]{64}$" |
| messageCount | integer | 是 | 会话摘要所覆盖的消息条数。 在所属结构适用时为必填项；最小值0；最大值20。；minimum: 0；maximum: 20 |
| scope | string | 是 | 模型或 Provider 的作用域标识。出现在绑定定义、模型事件、兼容性检查和模型调用上，用来区分模型或供应商所属范围，不是租户身份。 在所属结构适用时为必填项；固定值："RECENT_WINDOW_WITH_DIGEST"。；const: "RECENT_WINDOW_WITH_DIGEST" |

已受理、独立计量的 BUSINESS 元数据操作，不是聊天消息。只有 SUCCEEDED 状态携带与 kind 对应的非空 result，其他状态的 result 为 null；成功或待处理状态的 errorCode 为 null。TITLE 遵守手动标题修订保护；成功历史来源发生变化时以 CONVERSATION_CHANGED 失败。
