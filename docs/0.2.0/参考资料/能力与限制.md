# 能力与限制

本页区分当前实现、需要环境配置的能力与尚未开放的入口。依据为当前平台装配、公共合同和 SDK 源码；不以旧版本验收记录推定当前实现。

## 当前可用的能力

| 领域 | 当前实现 | 使用条件 |
| --- | --- | --- |
| 智能体执行 | DSH 驱动、取消、可靠收束、公共事件恢复 | 可用模型、权限、预算与 PostgreSQL |
| 会话交互 | 创建、改名、归档/恢复、编辑、摘要、问卷、审批、QUEUE / STEER 跟进 | 按服务端能力声明与当前状态操作 |
| 身份与发布 | 应用、主体、租户与角色隔离；凭证、OIDC、身份委托、资源版本与发布计划 | 认证边界和接入方权限配置 |
| 模型与工具 | 受控调用、共享预算、调用诊断、健康探测与人工证据 | 不把未知用量当作零，不自动重放未知副作用 |
| 知识问答 | INLINE / MANAGED / REMOTE、文件摄入、向量构建、文档权限、引用预览 | 上传解析需配置独立解析器，远程知识需接入服务 |
| 文件成果 | 平台托管 PDF、业务工具返回的显式文件引用 | PDF 字体与存储格式；业务文件存储/预览由接入方配置 |
| 控制台 | 资源管理、运行查询、审计、可靠观测、手动告警和受限留存 | 管理权限不授予读取业务正文的旁路 |

## 当前未开放或不能据此承诺的能力

| 项目 | 边界 |
| --- | --- |
| 多实例执行协调 | 默认单活；增加容器副本不构成多活支持 |
| 知识检索调试与知识评测 | 合同保留 5 个操作，服务端与控制台未提供 |
| 部分管理查询 | 应用活动运行分页、审计专项留存预览/执行入口尚未装配 |
| 自动告警与外部链路 | 自动告警评估、通知投递、OTLP 外发未配置，不能沿用旧版开放声明 |
| 业务预算人工结算 | 人工对账追加证据和有效投影，不统一修正根 Token、费用、跨 Run 配额或释放 UNKNOWN |
| 任意办公文件生成 | 当前文件成果不能理解为已支持生成 Word、Excel、PPT |
| 全量历史清理 | 默认关闭自动清理；普通留存入口不得删除可靠 Run、Session、事件和审批历史 |
| 生产容量保证 | 本地构建与测试不代表实际业务环境或容量验收 |

## 恢复与安全边界

- 普通 `context`、模型输出和 `appId` 都不是可信身份。
- 已发生的工具副作用不会因点击停止自动撤销。
- COMMIT、模型回执或工具副作用未知时，先读取原记录；不要自动重新执行。
- 临时正文预览可能丢失崩溃前尚未保存的尾部；可靠事件游标与历史才是恢复依据。
- 上下文压缩保留原始日志，摘要调用计入预算；压缩不是无损上下文或无限预算。
- 文档解析器有进程与资源约束，但不是操作系统级安全沙箱；Windows 进程树清理和 OCR 存在部署限制。
