# 完整示例

下面是一条可以拆开使用的最小路径：后台声明一个只读工具和一个默认智能体，配置指向本机平台，页面用现有 Bearer 登录打开基础聊天面板。类和配置是说明性片段。可编译的应用在文档仓库 `examples/0.2.0/`，链接写在文末。那些示例里的机组和用户对照都是本地替身，不代表真实设备或厂商验收。

## 1. 后台依赖

Java 17 与 Spring Boot 4。制品版本使用你实际 `publishToMavenLocal` 或拿到的同版本字符串；默认构建是 `0.2.0`。

::: code-group

```kotlin [Gradle Kotlin DSL]
dependencies {
    implementation("dev.sparktide:sdk-spring-boot-starter:0.2.0")
    implementation("dev.sparktide:sdk-model-openai-compatible:0.2.0")
    implementation("org.springframework.boot:spring-boot-starter-web")
}
```

```groovy [Gradle Groovy DSL]
dependencies {
    implementation 'dev.sparktide:sdk-spring-boot-starter:0.2.0'
    implementation 'dev.sparktide:sdk-model-openai-compatible:0.2.0'
    implementation 'org.springframework.boot:spring-boot-starter-web'
}
```

```xml [Maven]
<dependency>
  <groupId>dev.sparktide</groupId>
  <artifactId>sdk-spring-boot-starter</artifactId>
  <version>0.2.0</version>
</dependency>
<dependency>
  <groupId>dev.sparktide</groupId>
  <artifactId>sdk-model-openai-compatible</artifactId>
  <version>0.2.0</version>
</dependency>
```

:::

Java 8 业务把 Starter 换成 `sdk-spring-boot2-starter`，其余坐标版本保持一致。

## 2. 声明

::: code-group

```java [Java]
@AiProvider(baseUrl = "${OPS_MODEL_BASE_URL}", apiKey = "${OPS_MODEL_API_KEY}")
public class BusinessProvider extends OpenAICompatibleProvider {}

@AiModel(name = "business-model", model = "example-chat-model",
    provider = BusinessProvider.class, maxOutputTokens = 1024)
public final class BusinessModel extends BusinessProvider.Model {
    public BusinessModel() {}
}

@Component
public class EquipmentStatusTool {
    public record Input(String equipmentId) {}
    public record Output(String equipmentId, String state) {}

    @Tool(name = "equipment-status", description = "查询机组当前状态，只读")
    public Output execute(Input input, ToolContext context) {
        return equipmentService.status(input.equipmentId());
    }
}

@Agent(name = "main",
    instructions = "只根据工具结果回答设备状态。",
    model = {BusinessModel.class},
    tools = {EquipmentStatusTool.class},
    defaultAgent = true)
public final class OpsAssistant {}
```

```kotlin [Kotlin]
@AiProvider(baseUrl = "\${OPS_MODEL_BASE_URL}", apiKey = "\${OPS_MODEL_API_KEY}")
class BusinessProvider : OpenAICompatibleProvider()

@AiModel(name = "business-model", model = "example-chat-model",
    provider = BusinessProvider::class, maxOutputTokens = 1024)
class BusinessModel : OpenAICompatibleProvider.Model()

@Component
class EquipmentStatusTool {
    data class Input(val equipmentId: String)
    data class Output(val equipmentId: String, val state: String)

    @Tool(name = "equipment-status", description = "查询机组当前状态，只读")
    fun execute(input: Input, context: ToolContext): Output =
        equipmentService.status(input.equipmentId)
}

@Agent(name = "main",
    instructions = "只根据工具结果回答设备状态。",
    model = [BusinessModel::class],
    tools = [EquipmentStatusTool::class],
    defaultAgent = true)
class OpsAssistant
```

:::

`EquipmentStatusTool` 是普通 Bean。`OpsAssistant` 不需要 `@Component`。把 `example-chat-model` 换成供应商模型名，并在验证工具调用和流式之后，把对应能力标成 `Support.SUPPORTED`。写操作、知识过滤和主体映射分别见 [后端接入](./后端接入.md) 与 [身份与权限](./身份与权限.md)。

## 3. 配置

开发机先用 `DEVELOPMENT`，让声明能够同步。确认 `registrationReport()` 后，再以已发布定义运行生产模式。

```yaml
sparktide:
  application: ${SPARKTIDE_APP_ID:ops-assistant}
  platform:
    url: ${SPARKTIDE_PLATFORM_URL:http://127.0.0.1:18092}
    credential: ${SPARKTIDE_TOKEN:}
  callbacks:
    url: ${SPARKTIDE_PUBLIC_BASE_URL:http://127.0.0.1:8089}
    credential: ${SPARKTIDE_CALLBACK_TOKEN:}
    secret-reference: ${SPARKTIDE_CALLBACK_SECRET_REF:OPS_CALLBACK_TOKEN}
    ledger-directory: ${SPARKTIDE_LEDGER_DIR:./data/ledger}
    port: 8089
  bind-address: 127.0.0.1
  deployment:
    mode: DEVELOPMENT
    version: 1.0.0
  http:
    path: /api/ai
```

环境变量只放在进程环境或宿主密钥系统里。`SPARKTIDE_TOKEN` 与 `OPS_MODEL_API_KEY` 不进入前端打包，也不写入注册清单。平台必须能访问 `callbacks.url`。本机回环地址只在平台与业务同机时可用。

生产把 `deployment.mode` 改为 `PRODUCTION`。此模式启动时核验已发布定义，不在启动时发布。变更声明时递增 `deployment.version`，由受控作业调用 `SparkTideRegistration.release`。

## 4. 页面

前端安装 `0.2.0` 核心和 `0.2.0` 的 `ui-basic`，见 [接入总览](./接入总览.md)。`loginStore.token` 来自业务已有登录。

::: code-group

```ts [TypeScript]
import {createClient} from '@sparktide/frontend-sdk';

export const ai = createClient({
  baseUrl: '/api/ai',
  auth: {
    type: 'bearer',
    token: () => loginStore.token,
    identityKey: () => loginStore.sessionRevision,
  },
});
```

```js [JavaScript]
import {createClient} from '@sparktide/frontend-sdk';

export const ai = createClient({
  baseUrl: '/api/ai',
  auth: {
    type: 'bearer',
    token: () => loginStore.token,
    identityKey: () => loginStore.sessionRevision,
  },
});
```

:::

::: code-group

```tsx [React]
import {SparkTideProvider} from '@sparktide/frontend-sdk/react';
import {ChatPanel} from '@sparktide/ui-basic/react';
import '@sparktide/ui-basic/style.css';

export function Assistant() {
  return (
    <SparkTideProvider client={ai}>
      <ChatPanel agent="main" />
    </SparkTideProvider>
  );
}
```

```ts [Vue 3]
import {createApp} from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue';
import {ChatPanel} from '@sparktide/ui-basic/vue';
import '@sparktide/ui-basic/style.css';

createApp(ChatPanel, {agent: 'main'})
  .use(SparkTidePlugin, {client: ai})
  .mount('#assistant');
```

```ts [Vue 2]
import Vue from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue2';
import {ChatPanel} from '@sparktide/ui-basic/vue2';
import '@sparktide/ui-basic/style.css';

Vue.use(SparkTidePlugin, {client: ai});
new Vue({
  render: h => h(ChatPanel, {props: {agent: 'main'}}),
}).$mount('#assistant');
```

:::

页面通过业务站点的反向代理访问 `/api/ai`，从而保持同源 Cookie 或由页面附加 Bearer。退出登录时调用 `ai.reset()`；离开应用时 `ai.dispose()`。

## 5. 核对

1. 开发进程启动后，`SparkTideRegistration.registrationReport()` 没有冲突。
2. 用业务用户打开页面，发送「查询某设备」。网络请求的主机是业务后台，请求头是原登录，正文没有平台凭据。
3. 工具回调里的 `context.userId()` 是映射后的业务用户。Service 仍按原数据权限过滤。
4. 停止按钮或 `task.cancel()` 才会请求取消。关掉页面只断开本地事件流。
5. 切到生产模式前，定义已经发布，`deployment.mode` 为 `PRODUCTION`。

跟进、引用和文件要在平台能力打开后才出现。当前平台源码的跟进能力包含 `QUEUE` 与 `STEER`；若部署返回的 `modes` 为空，面板仍可普通发送。PDF 成果需要平台侧的字体和存储格式，见 [能力指南](../能力指南/README.md)。
