# 前端接入

前端 SDK 负责业务聊天的 HTTP、SSE、游标恢复、消息合并、审批、卡片和引用。视觉组件在 `@sparktide/ui-basic` 或 `@sparktide/ui-dashboard`。根包 `@sparktide/frontend-sdk` 只有客户端和框架状态，不带样式。

安装同版本 tarball 的步骤在 [接入总览](./接入总览.md)。核心版本是 `0.2.0`，两个界面包是 `0.2.0`，并且 peer 精确要求核心 `0.2.0`。peer 里的 React 是 `>=18 <20`，Vue 是 `^2.6.0 || ^3.5.0`。SDK 开发依赖里用来编译样例的版本是 React `19.1.0`、Vue `3.5.13`、Vue `2.7.16`。Vue 2 子路径不加载 Vue 3 运行时。

`baseUrl` 指向业务后台的聊天前缀，默认 `/api/ai`。认证只通过 `auth` 配置。下面先创建客户端，三个框架共用这一个对象。

::: code-group

```ts [TypeScript]
import {createClient} from '@sparktide/frontend-sdk';

export const ai = createClient({
  baseUrl: '/api/ai',
  auth: {
    type: 'bearer',
    token: () => loginStore.token,
    identityKey: () => loginStore.sessionRevision,
  },
});
```

```js [JavaScript]
import {createClient} from '@sparktide/frontend-sdk';

export const ai = createClient({
  baseUrl: '/api/ai',
  auth: {
    type: 'bearer',
    token: () => loginStore.token,
    identityKey: () => loginStore.sessionRevision,
  },
});
```

:::

已有 Cookie 登录：

::: code-group

```ts [TypeScript]
auth: {
  type: 'cookie',
  csrfToken: () => loginStore.csrfToken,
  identityKey: () => loginStore.sessionRevision,
}
```

```js [JavaScript]
auth: {
  type: 'cookie',
  csrfToken: () => loginStore.csrfToken,
  identityKey: () => loginStore.sessionRevision,
}
```

:::

Shiro 一类自定义头：

::: code-group

```ts [TypeScript]
auth: {
  type: 'headers',
  headers: () => ({token: loginStore.token}),
  identityKey: () => loginStore.sessionRevision,
}
```

```js [JavaScript]
auth: {
  type: 'headers',
  headers: () => ({token: loginStore.token}),
  identityKey: () => loginStore.sessionRevision,
}
```

:::

省略 `auth` 时使用当前源的 Cookie，并带上 `X-Requested-With`。字段含义和拒绝规则见 [身份与权限](./身份与权限.md)。普通请求时限 `timeoutMs` 默认 30000 毫秒；SSE 由读取时限管理。可选 `traceparent()` 只用于诊断关联。

应用退出或不再需要客户端时调用 `ai.dispose()`。它释放订阅和身份监测，不取消后台任务。

## 最小面板

三个入口都导入 `ChatPanel`，样式来自界面包，状态插件来自核心包。标签分别是 React、Vue 3 和 Vue 2。把 `@sparktide/ui-basic` 换成 `@sparktide/ui-dashboard` 即使用大屏外观，组件名和子路径相同。两套样式不要叠在同一面板上。

::: code-group

```tsx [React]
import {SparkTideProvider} from '@sparktide/frontend-sdk/react';
import {ChatPanel} from '@sparktide/ui-basic/react';
import '@sparktide/ui-basic/style.css';

export function Assistant() {
  return (
    <SparkTideProvider client={ai}>
      <ChatPanel agent="main" />
    </SparkTideProvider>
  );
}
```

```ts [Vue 3]
import {createApp} from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue';
import {ChatPanel} from '@sparktide/ui-basic/vue';
import '@sparktide/ui-basic/style.css';

createApp(ChatPanel, {agent: 'main'})
  .use(SparkTidePlugin, {client: ai})
  .mount('#assistant');
```

```ts [Vue 2]
import Vue from 'vue';
import {SparkTidePlugin} from '@sparktide/frontend-sdk/vue2';
import {ChatPanel} from '@sparktide/ui-basic/vue2';
import '@sparktide/ui-basic/style.css';

Vue.use(SparkTidePlugin, {client: ai});
new Vue({
  render: h => h(ChatPanel, {props: {agent: 'main'}}),
}).$mount('#assistant');
```

:::

`agent` 是已发布的智能体名称。名称会解析成精确版本；解析失败直接报错，不会改用默认智能体。省略 `agent` 时由业务后台选择已发布的默认入口。也可以传入 `{id, version}`，版本必须是具体语义化版本。

`ChatPanel` 也可以直接接收 `client`。文档仓库 `examples/0.2.0/react-chat`、`vue3-chat`、`vue2-chat` 里的自定义布局使用这种写法。同一页面的多块区域要共享会话时，仍用 Provider 或 Plugin 包一次。

面板在忙碌时仍可编辑。默认跟进模式是 `QUEUE`。服务端能力声明包含 `STEER` 后，可以把 `followUpMode` 设为 `STEER`。跟进列表、暂停、恢复和停止由同一 `ChatStore` 处理。能力端点没有开放跟进时，输入框的普通发送不受影响。

`nextSuggestions` 默认 `0`，表示不生成后续意图。设为 `1` 到 `5` 使用指定条数，设为 `'byAi'` 时由模型决定 0 到 5 条。`autoSummary` 在 Vue 面板上默认开启：一轮新回复结束后更新摘要。摘要短时留在当前视图，过期后保留旧内容直到下一次授权读取完成。切换身份或会话会清掉本地摘要缓存。

## 无界面状态

自定义布局使用与面板相同的状态。React 的 `useChat` 只接受选项对象；`client` 可省略并从 `SparkTideProvider` 读取。Vue 3 的 `useChat` 接受选项或返回选项的 getter。Vue 2 用 `createChatMixin`，组件上出现 `chatState` 和 `chat`。

::: code-group

```tsx [React]
import {useChat} from '@sparktide/frontend-sdk/react';
import {MessageList, ChatInput} from '@sparktide/ui-basic/react';

export function CustomChat() {
  const chat = useChat({agent: 'main'});
  return (
    <main>
      <MessageList messages={chat.messages} onCitation={chat.previewCitation} />
      <ChatInput chat={chat} />
    </main>
  );
}
```

```ts [Vue 3]
import {defineComponent, h} from 'vue';
import {useChat} from '@sparktide/frontend-sdk/vue';
import {MessageList, ChatInput} from '@sparktide/ui-basic/vue';

export const CustomChat = defineComponent({
  setup() {
    const chat = useChat(() => ({agent: 'main'}));
    return () => h('main', [
      h(MessageList, {messages: chat.messages.value, onCitation: chat.previewCitation}),
      h(ChatInput, {chat}),
    ]);
  },
});
```

```ts [Vue 2]
import Vue from 'vue';
import {createChatMixin, type ChatMixinState} from '@sparktide/frontend-sdk/vue2';
import {MessageList, ChatInput} from '@sparktide/ui-basic/vue2';

export const CustomChat = Vue.extend({
  mixins: [createChatMixin({agent: 'main'})],
  render(this: Vue & ChatMixinState, h) {
    return h('main', [
      h(MessageList, {props: {messages: this.chatState.messages, onCitation: this.chat.previewCitation}}),
      h(ChatInput, {props: {state: this.chatState, actions: this.chat}}),
    ]);
  },
});
```

:::

无框架页面直接创建 `ChatStore`：

::: code-group

```ts [TypeScript]
const chat = ai.createChat({
  agent: 'main',
  context: () => ({projectId: selectedProject.id}),
});
const off = chat.subscribe(() => render(chat.getState()));
chat.start();
chat.setInput('查询设备');
chat.send();
// 页面卸载：off(); chat.dispose();
```

```js [JavaScript]
const chat = ai.createChat({
  agent: 'main',
  context: () => ({projectId: selectedProject.id}),
});
const off = chat.subscribe(() => render(chat.getState()));
chat.start();
chat.setInput('查询设备');
chat.send();
```

:::

`send` 以及界面动作返回 `void`。失败写入状态里的 `error`，并调用 `onError`。需要等待运行终态时使用领域 API：

::: code-group

```ts [TypeScript]
const task = await ai.chat.run({message: '查询设备', agent: 'main'});
const result = await task.completed();
```

```js [JavaScript]
const task = await ai.chat.run({message: '查询设备', agent: 'main'});
const result = await task.completed();
```

:::

`chat.run` 不自动订阅。`completed`、`watch` 和界面观察共享一条事件流。取消等待、卸载视图、`reset` 和 `dispose` 只关闭本地读取。`task.cancel()` 或界面停止才会请求取消后台任务。

组合部件、主题和业务卡片见 [自定义界面](./自定义界面.md)。客户端方法表见 [前端 SDK](../参考资料/前端SDK.md) 与 [前端核心](../参考资料/SDK依赖/前端核心.md)。无界面源码在文档仓库 `examples/0.2.0/core-client`。

## 会话、引用和文件

| 能力 | 调用 | 行为 |
| --- | --- | --- |
| 会话列表 | `ai.conversations.list({limit, offset, archived})` | 默认每页 50，范围 1 到 200 |
| 会话消息 | `ai.conversations.get(id, {limit, before})` | 使用返回的 `nextBefore` 读取更早消息；单页消息不超过 20 条 |
| 归档 / 恢复 | `archive` / `restore` | 保留消息、摘要和运行历史，不自动清理 |
| 改名 / 删除 | `rename` / `delete` | 删除不取消活动任务；活动会话由服务端拒绝 |
| 原位编辑 | `edit` | 保留旧历史快照，未知结果用原幂等键恢复 |
| 摘要与标题 | `getSummary`、`generateSummary`、`generateTitle` | 读取摘要不隐式调用模型。生成标题默认不覆盖手工标题 |
| 引用预览 | `ai.citations.preview(runId, id)` | 每次重新授权。业务查询快照可用 `formatReferencePreview` 映射成标题和正文 |
| 平台 PDF | `ai.artifacts.download(runId, id)` | 沿用当前登录，不生成新文件 |
| 业务文件 | `onDownloadArtifact` / `onPreviewArtifact` | SDK 不向业务地址附加认证头，由宿主自己的客户端下载 |

面板默认先显示最近消息，并提供加载更早消息。历史工具不会在恢复时重放。

## 跟进命令

领域入口是 `ai.followUps`：

| 方法 | 作用 |
| --- | --- |
| `capabilities()` | 读取 `protocolVersion: "1.0"`、`modes` 和固定的 `maxItems: 32` |
| `list(conversationId)` | 读取有界回执，不创建运行 |
| `submit(conversationId, input)` | `mode`、`message`、调用方保存的 `idempotencyKey`。`QUEUE` 可带智能体；`STEER` 带 `runId` |
| `update` / `remove` | 修改或移除尚未认领的 `QUEUE`，使用条目修订号 |
| `control(conversationId, revision, action)` | `PAUSE`、`RESUME` 或 `STOP`，使用会话修订号 |

`idempotencyKey` 是 1 到 128 个可见 ASCII 字符。编辑不更换创建时的幂等键。受理不等于已经应用到运行。晚到的引导不会自动改成排队。

面板里的 `FollowUpList` 绑定同一状态。直接调用领域 API 时，写操作失败会拒绝 Promise，而不是返回布尔成功。
