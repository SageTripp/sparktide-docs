# 开发接入

业务系统接入启澜时，后台使用后端 SDK 声明模型、智能体和工具，页面使用前端 SDK 复用现有登录。浏览器只访问业务后台的聊天入口，平台应用凭据留在后台。

本目录对应平台源码版本 `0.2.0`。后端 SDK 默认构建版本是 `0.2.0`，前端核心是 `0.2.0`。这些版本来自当前源码，尚未作为新的 Maven Central 或 npm registry 公开发行。版本对照和本地制品见 [接入总览](./接入总览.md)。

## 阅读顺序

1. [接入总览](./接入总览.md)：版本、本地制品、模块选择和一条可执行的接入顺序。
2. [后端接入](./后端接入.md)：Java 17 或 Java 8 依赖、类型化声明、配置和发布。
3. [身份与权限](./身份与权限.md)：现有登录、主体映射、工具回调和数据权限。
4. [前端接入](./前端接入.md)：React、Vue 3、Vue 2 的导入和最小页面。
5. [自定义界面](./自定义界面.md)：组合部件、主题、业务卡片和可选通用组件。
6. [HTTP 接入](./HTTP接入.md)：不使用前端 SDK 时调用业务聊天 HTTP。
7. [完整示例](./完整示例.md)：可组合的最小后台、配置和页面，并区分仓库内可编译示例。
8. [Agent 技能](./Agent技能.md)：把版本匹配的接入规则和离线参考交给开发 Agent。

接口、配置键和错误边界的稳定入口仍是 [后端 SDK](../参考资料/后端SDK.md) 与 [前端 SDK](../参考资料/前端SDK.md)。各依赖的参数章节分别收录在这两个分组下。接入步骤以本目录为准。
