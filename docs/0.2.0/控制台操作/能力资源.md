# 能力资源

「资源」页管理八类注册记录。智能体、工具和交互界面在这里起草和发布；知识文档正文不在定义 JSON 里编辑。


## 范围

模型四类的探测和配额见 [模型与凭据](./模型与凭据.md)。知识文档、权限和任务见 [知识与文档](./知识与文档.md)。

## 步骤

1. 选择应用后打开 `#registry`。页头有「刷新真实记录」。
2. 点类型按钮。八类及界面文案为：智能体 `agents`、工具 `tools`、知识 `knowledge`、交互界面 `ui-capabilities`、模型供应商 `model-providers`、模型 `models`、模型绑定 `model-bindings`、模型档案 `model-profiles`。
3. 从列表选择一条记录。编辑器显示该记录的定义 JSON。切换类型或离开页面前，未保存草稿会要求确认。
4. 修改后点「保存草稿」。若本地 JSON 无法解析、根不是对象或超过 128KiB，按钮不会提交。
5. 草稿与服务器一致后，点「发布当前草稿」。确认框会写明 `id@version`。取消确认则不发布。
6. 智能体发布后，回到概览把默认入口指到该版本。工具和界面发布后，还要被某个已发布智能体允许，才会进入新的执行计划。

`USER` 只能看到权限说明。页面不会发管理读写。

## 配置

定义字段由服务端校验。控制台不提供向导，也不把缺省字段写回服务器。编辑器只放定义对象：资源 `id` 和版本在创建区另填。`status`、`revision` 不能写进定义。各类型的字段含义、缺省和完整示例：

| 类型 | 填写时先看 | 编辑器里至少要能认出的对象 |
| --- | --- | --- |
| `agents` | [智能体](../能力指南/智能体.md) | `systemPrompt` 为 1 到 32768 个字符；`modelProfile` 为 `{ "id", "version" }`。省略 `maxSteps` 时执行按 8 步，省略 `maxToolCalls` 时按 16 次，不是无上限。写成 `-1` 才表示该项不封顶 |
| `tools` | [业务工具](../能力指南/业务工具.md) | `effect` 为 `READ`、`COMPUTE`、`WRITE` 或 `DANGEROUS`。`roles` 至少包含 `USER` 或 `APP_ADMIN`。`inputSchema` 与 `outputSchema` 是受限 Schema，对象要 `additionalProperties: false`。`endpoint` 通过 JSON 检查后仍可能被 origin 白名单拒绝 |
| `ui-capabilities` | [界面与文件成果](../能力指南/界面与文件成果.md) | `fallback` 为非空文本。`interaction` 只在需要时写 `FORM` 或 `QUESTION`。普通属性用受限 Schema；GenUI 才额外写 `$schema` |
| `knowledge` | [知识问答](../能力指南/知识问答.md) | `mode` 为 `INLINE`、`MANAGED` 或 `REMOTE`。`INLINE` 的文档在定义内；`MANAGED` 的正文用下方文档面板，不写进定义 JSON |
| `model-providers`、`models`、`model-bindings`、`model-profiles` | [模型](../能力指南/模型.md) | 供应商先写 `mode` 与 `endpoint`。模型用 `provider` 指向供应商，并用 `modelId` 写厂商模型名。绑定用 `model` 指向模型。档案用 `binding` 指向绑定 |

一份最小智能体定义可以贴成：

```json
{
  "systemPrompt": "只根据已授权资料回答。",
  "modelProfile": { "id": "default-profile", "version": "1.0.0" },
  "entryPolicy": { "mode": "APPLICATION" }
}
```

引用的档案、工具、知识和界面必须是执行时可解析的已发布版本。只创建草稿不会使聊天可用。

状态标签：`DRAFT` 显示「草稿」，`PUBLISHED` 显示「已发布」，`REVOKED` 显示「已撤销」。

待核对期间，类型切换和再次保存会被锁定。先点「刷新核对」或错误区里的「重试」，确认服务器内容后再决定是否采用本地草稿。

## 结果

- 新草稿提示「新草稿已创建；未自动发布。」
- 保存不会连带发布。发布是单独按钮，且要求没有未保存改动。
- 结果未知时保留原 `id`、`version`、定义和 `revision`，页面不会自动重试或再次创建。
- 已发布版本不能当草稿继续改。新行为要新的 `x.y.z`。
