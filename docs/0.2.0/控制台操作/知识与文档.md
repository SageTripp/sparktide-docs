# 知识与文档

知识注册记录位于「资源」的 `knowledge`。只有选中 `MANAGED` 知识时，文档、访问策略和任务面板才会发起对应请求。检索调试和知识评测没有页面。


## 范围

三种知识模式的运行语义见 [知识问答](../能力指南/知识问答.md)。本文只记录控制台能点的操作。

## 步骤

1. 在「资源」选择「知识」，打开一条 `MANAGED` 记录。非该模式、未选应用或 `USER` 时，文档面板不做读取、预览、保存或删除。
2. 展开文档列表后才请求摘要。每页 20 条，最多展示 1000 条范围内的分页。列表只有摘要，编辑区不会预填已有正文。
3. 新建或修改当前输入的 `id`、标题、来源和正文。正文本地上限 65536。点「预览当前输入」只计算这段文字，不读取旧正文。
4. 在 `DRAFT` 版本点「保存草稿」。保存按所选摘要的 `expectedDocumentVersion` 做条件更新。成功且结果为 `INDEXED` 时，文档仍未发布。
5. 需要删除时点「删除当前文档」。确认文案说明删除只提交 `documentId`，没有版本 CAS。服务端按当前状态执行。
6. 展开「文档级访问策略」。未点读取前不显示规则，也不能保存。读取后再改规则，填写原因，点「保存访问策略」或「保存并停用访问策略」。
7. 展开文件或向量页签后才读取任务，每页 20 条。上传文件或开始向量构建都只针对 `DRAFT`。点「取消任务」或对应的重试按钮前，先确认当前页 revision。

已发布或已撤销的知识版本上，保存和删除被禁用。预览仍只计算当前输入。

## 配置

| 控件 | 实际行为 |
| --- | --- |
| 重复策略 | 本地可选 `UPSERT`、`SKIP`、`REJECT`。`SKIPPED` 没有写入新文本，页面仍视为未保存 |
| 文档租户 | 摘要里的真实租户才会用于保存和预览。空租户表示应用共享，保存不会改写成当前操作者租户 |
| 访问策略 revision 0 | 仅在已经读到服务端默认规则后出现。未读取时不能拿 0 去保存 |
| 停用策略 | 会撤销该文档放行，并推进 `knowledgeAccessEpoch` |
| 上传格式 | 服务端接受 `txt`、`md`、`pdf`、`docx`、`xlsx`、`pptx`、`png`、`jpg`、`jpeg`。未配置解析器时上传失败 |
| 向量构建 | 「开始向量构建」提交当前草稿版本的构建任务。失败后「重试（新建 job）」创建新任务 |
| 文件重试 | 「重试（同 job / attempt+1）」沿用原任务并增加尝试次数 |
| 回答来源 | 会话中的引用预览有「显式重试」和「收起片段」。平台管理员、未选应用或应用身份不一致时不读取片段正文 |

任务区默认不轮询、不自动重试、不下载原件。revision 变化后，在成功刷新当前页之前不能再取消、重试或按旧 revision 操作。

若保存或删除结果未知，点「只读刷新摘要」或「只读核对文件/向量任务」。解除锁定前必须勾选已核对。本地正文不会被服务器摘要自动合并。

## 结果

- 草稿文档保存成功的提示写明 `INDEXED`，并说明未自动发布。
- 删除后本地文本留在未保存的新文档草稿中，不会自动重建。
- 412 或未知结果会阻断再次写入，直到显式采用新的服务器基线。
- 访问策略保存后显示新的服务端 revision。采用服务器策略本身不再写一次。
- 没有「检索调试」「运行知识评测」或评测历史按钮。不要用空文档列表表示评测已通过。
