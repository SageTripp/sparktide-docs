# 控制台操作

控制台是同源的 React 管理界面，入口为 `/console/`。导航、按钮和空状态都来自当前页面代码；本文不补充源码里没有的菜单。


## 范围

读者是开发、集成和运维人员。业务用户的默认界面在接入方页面，不在本控制台。能力边界见 [能力指南](../能力指南/README.md)。

## 步骤

1. 打开已启用控制台的服务。生产构建后的路径是 `/console/`。本地 `npm run dev:console` 固定在 `127.0.0.1:5173`，只把 `/v1` 代理到 `127.0.0.1:18092`。
2. 在登录页输入访问令牌并点「登录」。页面没有默认账号、随机令牌或后端地址框。提交后输入立即清空。
3. 登录成功后，侧栏显示服务端返回的角色、主体、租户和应用。角色不会由浏览器推断。
4. 用「当前应用」切换应用。有未保存本地草稿时，离开前会要求确认；已受理的服务端任务不会停止。
5. 按角色进入下表中的导航。地址哈希为 `#overview`、`#registry`、`#runs`、`#audit`、`#operations`。
6. 结束时点「退出登录」。凭据只在页面内存中，刷新后需要重登。退出不会取消服务端任务。

## 配置

| 导航 | 哈希 | 谁能看到管理数据 |
| --- | --- | --- |
| 概览 | `#overview` | `APP_ADMIN`、`PLATFORM_ADMIN` 读取应用、指标和已发布智能体。`USER` 不发起这些请求，默认进入会话页 |
| 资源 | `#registry` | 仅管理者。`USER` 看到权限说明，且不读取注册表 |
| 会话与运行 | `#runs` | 应用身份可操作本人会话。平台管理员不读取业务队列和业务会话正文 |
| 审计 | `#audit` | 仅管理者。每次查询固定一个快照，每页 50 条 |
| 运维与评测 | `#operations` | 管理者。`USER` 不请求管理接口。脱敏和留存页签只给平台管理员 |

工作区还有「刷新应用列表」。非 `USER` 可打开「个人资料」。配额面板在概览中默认折叠，第一次展开才加载。

页面崩溃时显示「页面暂时无法显示」和「退出并清除页面凭据」。该按钮只清本页内存。

## 结果

- 列表、指标和健康都来自当前授权 API。加载完成前不显示占位数字。
- 写操作遇 412 会保留本地草稿。结果未知时先只读核对，不自动重试。
- 控制台不提供知识检索调试、知识评测、应用活动运行分页、审计专项留存或告警外发开关。
- 开发代理不能改成任意 API 源。
