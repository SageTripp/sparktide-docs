# 应用与授权

控制台身份来自访问令牌。平台管理员、应用管理员和普通用户看到的按钮不同。创建应用不会自动得到可聊天的智能体。


## 范围

本文只写登录、应用创建、默认智能体和个人资料。模型密钥和出站白名单在服务环境中配置，见 [模型与凭据](./模型与凭据.md) 与 [网络与认证](../部署运维/网络与认证.md)。

## 步骤

1. 向运行中的控制台提交令牌。平台管理员令牌对应 `SPARKTIDE_ADMIN_TOKEN`。OIDC 令牌只在发行者、JWKS 和受众三项都配置后才启用，且联邦角色只有 `USER` 与 `APP_ADMIN`，不能从令牌自报成平台管理员。
2. 确认侧栏角色。`PLATFORM_ADMIN` 可管理可见应用；`APP_ADMIN` 限于被授权应用；`USER` 使用会话能力，不读取管理注册表。
3. 没有可见应用时，概览显示「开始配置启澜」。只有平台管理员能看到「新建应用」。
4. 填写应用 ID 和名称，点「创建应用」。ID 须小写字母开头，仅含小写字母、数字和连字符，最长 64。名称 1 到 128 个字符，不能含控制字符。本地检查不能代替服务端。
5. 创建成功后状态为 `DRAFT`。继续到「资源」发布智能体、模型和工具，再回到「切换默认 Agent」。
6. 在已发布智能体中选择 `id@version`，提交切换。请求使用当前应用 `revision` 作为条件。
7. 非普通用户可点「个人资料」，修改显示名和头像配色后保存。资料不是授权，也不会改变角色。

若创建返回结果未知，输入会保留并停止重复提交。点「只读核对创建结果」。未找到时不要直接再次创建。

## 配置

| 界面元素 | 谁可以使用 | 服务端结果 |
| --- | --- | --- |
| 登录 | 持有令牌的操作者 | 失败不回显令牌，不写入浏览器存储、URL 或日志 |
| 创建应用 | 仅 `PLATFORM_ADMIN` | 新建为 `DRAFT`，没有默认 Agent |
| 刷新 | 管理者且已选应用 | 重新读取应用详情和已发布智能体 |
| 切换默认 Agent | `PLATFORM_ADMIN` 或 `APP_ADMIN` | 只能选真实 `PUBLISHED` 版本。412 表示 revision 已变，须先点「刷新」 |
| 个人资料 | 非 `USER` | 只更新显示资料 |
| 当前应用下拉 | 已登录身份 | 空列表文案为「未配置」，不会虚构一个默认应用 |

应用 ID 在接口中是作用域，不是权限。请求正文里的 `appId`、调用者 Context 和模型输出都不能提升角色。

## 结果

- 未设置默认 Agent 时，概览明确写「尚未配置」，应用不能视为就绪。
- 切换成功后顶栏显示新的应用状态和 `revision`。
- 同一页面重复点击创建或切换会被拒绝，避免双提交。
- 平台管理员打开会话页时，不能用管理身份读取业务队列或业务正文。
