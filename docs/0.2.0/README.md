## 先确认版本

平台与 SDK 的本地版本声明统一为 0.2.0。本文档描述当前源码实现，不把版本号对齐等同于公开发行或生产验收。制品、协议和业务资源版本的区别见[版本与兼容性](参考资料/版本与兼容性.md)。

本次只维护当前版本。旧站内容独立归档，不进入本站导航与搜索；不将旧版下载包当作 0.2.0 安装包。
