# 环境变量

下表只收录启动、初始化和容器健康检查真正读取的变量。未列出的名字不会被当前进程当作配置。服务不自动加载 `.env`。


## 范围

注入方式见 [Docker部署](./Docker部署.md) 与 [独立进程部署](./独立进程部署.md)。认证组合见 [网络与认证](./网络与认证.md)。

## 步骤

1. 在即将启动的那个进程里设置变量。子进程看不到未导出的值。
2. 必填项用 `Read-Host` 或外部密钥注入。示例一律使用占位符 `<...>`，不提供可登录的默认口令。
3. 启动前核对类型：布尔只认小写 `true` 或 `false`，端口必须是 1 到 65535 的安全整数。
4. 初始化完成后执行 `Remove-Item Env:SPARKTIDE_ALLOW_DATABASE_INITIALIZATION`。长期运行的进程不需要这个变量。
5. 修改 keyring、绑定地址或 origin 白名单后要重启。运行中的进程不会热加载这些值。

生成托管密钥时只在本机取 32 字节随机数并做标准 base64，不要把输出提交到仓库：

```powershell
$bytes = New-Object byte[] 32
[System.Security.Cryptography.RandomNumberGenerator]::Fill($bytes)
[Convert]::ToBase64String($bytes)
```

keyring 形如 `{"<密钥标识>":"<上一步的标准base64>"}`。标识匹配 `[A-Za-z0-9_-]{1,64}`。`SPARKTIDE_CREDENTIAL_ACTIVE_KEY` 必须是其中一只已经存在的标识。空对象配空 active key 可以启动，但一旦调用托管凭据会得到 503 `CREDENTIAL_STORE_DISABLED`。

## 配置

### 进程必填与监听

| 变量 | 缺省 | 加载规则  含义、用途与填写场景 |
| --- | --- | --- | --- |
| `SPARKTIDE_NODE_DATABASE_URL` | 无 | 必填。没有内存库。连接串由操作者提供，例如 `postgres://<用户>:<已编码口令>@<主机>:5432/<库名>`  连接平台状态库。每次部署必填；使用专属库，口令中的特殊字符须做 URL 编码。 |
| `SPARKTIDE_NODE_PORT` | `18092` | 1 到 65535 的整数  平台进程监听端口。端口冲突或反向代理改接入端口时设置，例如 18093。 |
| `SPARKTIDE_NODE_BIND` | `127.0.0.1` | 只能是 `127.0.0.1`、`0.0.0.0`、`::1`、`::`  选择监听网卡。仅本机代理保持回环；容器内通常使用 0.0.0.0，宿主暴露范围另由端口映射控制。 |
| `SPARKTIDE_NODE_CONSOLE_ENABLED` | `true` | 只能是 `true` 或 `false`  是否由平台提供控制台静态页面。只部署 API、控制台另行托管时设为 false。 |
| `SPARKTIDE_NODE_CONSOLE_DIR` | 构建产物中的控制台目录 | 只提供明确的构建结果。目录不可用则启动失败，不回退源码  控制台构建文件的位置。自定义制品目录布局时设置，不能指向前端源码目录。 |
| `SPARKTIDE_REPORT_FONT_FILE` | 不设置 | 非空时传给 PDF 渲染。不设置则不注册 `generate_pdf_report`  PDF 报告字体文件。需要生成报告时配置进程可读的字体路径；中文报告选用包含中文字形的字体。 |

### 身份、出站与密钥

| 变量 | 缺省 | 加载规则  含义、用途与填写场景 |
| --- | --- | --- | --- |
| `SPARKTIDE_ADMIN_TOKEN` | 空字符串 | 空字符串不是可用口令。平台管理员令牌由操作者注入  用于平台管理认证。首次管理及运维接入时注入，不能放进浏览器业务示例或作为模型密钥。 |
| `SPARKTIDE_OIDC_ISSUER` | 空 | 与 JWKS、受众要么全空，要么全填。全空表示不启用联邦登录  可信身份服务的签发者。接入 OIDC 时填写与令牌 iss 一致的发行者地址。 |
| `SPARKTIDE_OIDC_JWKS_URI` | 空 | 必须是 HTTPS。仅当允许本地 HTTP 时，才接受 `127.0.0.1`、`localhost`、`[::1]`  可信身份服务的签名公钥集地址。与 issuer 配套配置，用于校验令牌签名。 |
| `SPARKTIDE_OIDC_AUDIENCE` | 空 | 专用 API 受众。令牌不能自带 `jku` / `x5u` 来换密钥  该平台 API 对应的受众标识。接入 OIDC 时填写身份服务分配的值，避免接受发给其他服务的令牌。 |
| `SPARKTIDE_OIDC_ALLOW_LOCAL_HTTP` | 不是 `true` 即关闭 | 只有精确值 `true` 才允许上述本机 HTTP  本机 OIDC 联调开关。仅本机身份服务没有 HTTPS 时启用；不放开任意远程 HTTP。 |
| `SPARKTIDE_ALLOW_HTTP` | 不是 `true` 即关闭 | 关闭时出站端点必须是 HTTPS  允许模型、工具等出站请求使用 HTTP。仅接入明确允许的非 TLS 服务时打开，仍需 origin 白名单。 |
| `SPARKTIDE_ALLOWED_ORIGINS` | 空 | 逗号分隔的精确 origin，去掉首尾空格和末尾斜杠。不能带路径、查询或片段  指定平台可以访问哪些模型或业务服务源站。例如 https://api.example.com,https://business.example.com。必须与实际出站地址匹配。 |
| `SPARKTIDE_CREDENTIAL_KEYRING` | 空，视为 `{}` | JSON 对象。每个值是标准 base64 的 32 字节密钥  托管凭据的加密密钥集合。需要在控制台管理模型密钥时配置；轮换时保留解密既有记录所需的旧密钥。 |
| `SPARKTIDE_CREDENTIAL_ACTIVE_KEY` | 空 | 有任何密钥时必须指向 keyring 中的标识  新写入凭据使用的密钥标识。初次配置或轮换密钥时设置为 keyring 中的一个键，例如 key-2026。 |
| `SPARKTIDE_CREDENTIALS_KEYRING` | 禁止 | 非空即启动失败。正确名字是单数 `CREDENTIAL_KEYRING`  错误拼写示例，不可使用。发现此配置时改为上面的单数形式。 |
| `SPARKTIDE_CREDENTIALS_ACTIVE_KEY` | 禁止 | 同上，没有复数别名  错误拼写示例，不可使用。发现此配置时改为上面的单数形式。 |
| `SPARKTIDE_SECRET_NAMES` | 空 | 逗号分隔的环境变量名。这些名字的值才会作为出站引用  将指定环境变量登记为可引用的出站凭据，例如 MODEL_API_KEY。资源的 secretRef 填这个名字，不填密钥正文。 |
| `SPARKTIDE_SECRET_ORIGINS` | 空 | `名字=https://<主机>`，逗号分隔。每个名字都要有 origin  限定每个环境凭据可发往的源站，例如 MODEL_API_KEY=https://api.example.com；随 SECRET_NAMES 一起配置。 |
| `SPARKTIDE_SECRET_APPLICATIONS` | 空 | `名字=<应用>;<应用>`。分号分隔应用  限定每个环境凭据允许使用的应用，例如 MODEL_API_KEY=helpdesk;operations；按实际应用授权填写。 |

`SPARKTIDE_SECRET_NAMES` 不能使用 `SPARKTIDE_ADMIN_TOKEN`、keyring 变量或 `SPARKTIDE_NODE_DATABASE_URL`。比较时按大写处理，避免 Windows 环境变量大小写不敏感造成绕过。

### 解析器

| 变量 | 缺省 | 加载规则  含义、用途与填写场景 |
| --- | --- | --- | --- |
| `SPARKTIDE_NODE_PARSER_JAVA` | 空 | Java 17 可执行文件的绝对路径  独立解析器所用的 Java 程序。需要托管文档上传解析时，与下面三项一起配置。 |
| `SPARKTIDE_NODE_PARSER_CLASSPATH` | 空 | 绝对路径 JSON 数组，1 到 256 项。不是冒号或分号分隔的字符串  解析器与依赖 Jar 的加载列表。部署解析器制品时填写各 Jar 的绝对路径，保留 JSON 数组格式。 |
| `SPARKTIDE_NODE_PARSER_PLUGIN` | 空 | 运维固定的插件名，例如 `builtin`。用户请求不能选择代码  选择受信的文档抽取插件。使用内置抽取器时填写 builtin。 |
| `SPARKTIDE_NODE_PARSER_TMPDIR` | 空 | 私有临时目录绝对路径  解析器处理中间文件的目录。为运行账户准备专用可写目录，不与公开下载目录混用。 |
| `SPARKTIDE_NODE_PARSER_OCR` | 空 | 可选 OCR 可执行文件。默认镜像不提供  OCR 程序路径。只有需要识别扫描文档且已安装配套工具时配置。 |
| `SPARKTIDE_NODE_PARSER_OCR_LANGUAGES` | 空 | 可选语言列表。实现缺省语言为 `eng`  OCR 识别语言。识别非英文扫描件时按已安装的 OCR 语言包配置；仅设置语言不能替代安装 OCR。 |

`JAVA`、`CLASSPATH`、`PLUGIN`、`TMPDIR`、`OCR`、`OCR_LANGUAGES` 全部为空时不创建解析器。前四项只要有一项非空，其余三项也必须非空，否则进程拒绝启动。

### 只在初始化或容器健康检查中读取

| 变量 | 缺省 | 谁读取  含义、用途与填写场景 |
| --- | --- | --- | --- |
| `SPARKTIDE_ALLOW_DATABASE_INITIALIZATION` | 未设置即拒绝 | 只有精确 `true` 才执行 `db:initialize`。编排里的 `initialize` 服务会自己设为 `true`  允许当前初始化命令安装或升级数据库结构。只在确认目标库和备份之后临时开启。 |
| `SPARKTIDE_DB_PASSWORD` | 无，`:?` 失败 | 仅 `compose.yaml`。平台进程更认 `SPARKTIDE_NODE_DATABASE_URL`  Compose 中 PostgreSQL 用户口令，同时用于默认数据库 URL。容器部署时提供，不是平台直接读取的连接参数。 |
| `SPARKTIDE_NODE_HOST_PORT` | `18092` | 仅编排，映射到宿主回环  Compose 对宿主机发布的端口。宿主 18092 已占用时修改，不改变容器内监听端口。 |
| `SPARKTIDE_NODE_BUILD_TARGET` | `runtime` | 仅编排的 `main` 构建目标。`initialize` 始终是 `runtime`  Compose 构建镜像的阶段。普通运行选 runtime；需要独立解析器的镜像选 runtime-parser。 |
| `SPARKTIDE_HEALTH_TIMEOUT_MS` | `4000` | 仅 `scripts/container/health.mjs`。允许 500 到 30000 的整数  容器健康探测等待时间，单位毫秒。健康探测连接较慢时在允许范围内调整，不改变聊天任务期限。 |

连接池大小和语句超时不在环境变量中，见 [独立进程部署](./独立进程部署.md)。

## 结果

- 配置错误信息只包含变量名，不回显令牌、keyring 或连接串。
- OIDC 三项只填一部分时，启动失败并要求三项一起设置。
- origin 不是精确源站时，启动失败。Registry 里先写过的 URL 不会因此获得出站权。
- 健康检查超时变量不影响业务请求的 30 秒请求超时。
