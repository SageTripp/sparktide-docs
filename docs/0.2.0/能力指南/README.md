# 能力指南

启澜 `0.2.0` 是单活的 Node.js 智能体运行与治理平台。DSH `0.2.1-rc.3` 是唯一 Agent 循环；PostgreSQL 保存可靠事实；React 控制台面向开发、集成与运维人员。


## 范围

本栏目说明当前进程实际提供的模型、智能体、工具、知识、会话、界面成果和版本边界。接入步骤见 [快速开始](../快速开始/README.md) 与 [开发接入](../开发接入/README.md)。部署命令见 [部署运维](../部署运维/README.md)。限制汇总见 [能力与限制](../参考资料/能力与限制.md)。

不在本栏目承诺的事项：

| 事项 | 当前边界 |
| --- | --- |
| 第二套 Agent 循环 | 不提供。执行、压缩、工具循环都属于同一版 DSH |
| 多活或只加副本即可扩展 | 不提供。同一数据库上第二个执行器拿不到顾问锁就会启动失败 |
| 知识检索调试与知识评测 | 公共合同保留 5 个操作，服务端与控制台都未装配 |
| 应用活动运行分页 | 合同有 `GET /v1/apps/{app}/activity/runs`，当前 HTTP 入口未注册 |
| 审计专项留存预览/执行 | 合同有对应操作，当前留存路由未注册；普通留存不能代替 |
| 自动告警外发与 OTLP | 状态固定为未配置。界面可以手动评估规则，不能当成已通知或已导出链路 |
| 集群、Redis 运行时、Word/Excel/PPT 成果 | 当前部署入口与成果实现都不包含这些能力 |

## 步骤

1. 确认运行进程版本为 `0.2.0`，Node `24.22.1`、npm `10.9.4`。
2. 确认 PostgreSQL 已由显式初始化命令升到执行库格式 21，而不是只改元数据版本号。
3. 在控制台用真实身份查看已发布资源；`appId`、模型输出和用户 Context 都不是授权依据。
4. 对照下表判断能力是否可对用户开放。合同里出现的路径，要以服务端是否注册为准。

## 配置

| 条件 | 不满足时的结果 |
| --- | --- |
| `SPARKTIDE_NODE_DATABASE_URL` 指向已初始化的 PostgreSQL | 进程无法启动，没有内存库替代 |
| 执行库 `st_node_execution_meta.version` 等于源码常量 `21` | 执行器启动失败，并提示先显式执行数据库初始化 |
| 模型供应商、绑定和档案已发布，且出站 origin 在白名单 | 聊天返回能力不可用，而不是静默改用其他模型 |
| 需要 PDF 时配置可读的 `SPARKTIDE_REPORT_FONT_FILE` | 不注册 `generate_pdf_report` |
| 需要文件解析时同时配齐 Java 17 解析器四项 | 上传与重试返回 503，默认镜像不带 Java |

## 结果

- 可以受控调用已发布模型、工具和知识，并保留会话、审批、预算和运维记录。
- 取消、断线读取和连接失联围栏以 PostgreSQL 已提交事实为准。
- 未知提交、未知工具副作用和未知模型结果不会自动重放。
- 配置价目、供应商用量和人工证据是不同事实；缺失不能写成 0。
