# 知识问答

知识来源有三种：`INLINE`、`MANAGED`、`REMOTE`。回答引用只收录正文实际使用、且能对上可靠记录的来源。检索调试和知识评测的 5 个合同操作当前不能调用。


## 范围

本文说明三种模式、文档权限、解析器和引用预览。控制台按钮见 [知识与文档](../控制台操作/知识与文档.md)。业务侧协议细节见 [开发接入](../开发接入/README.md)。

## 步骤

1. 注册 `knowledge`。`mode` 只能是 `INLINE`、`MANAGED` 或 `REMOTE`。定义 `topK` 为 1 到 10，缺省为 3。
2. `INLINE`：在定义中放入 1 到 100 篇文档，发布后按词项检索。它与 `MANAGED` 的评分算法不同。
3. `MANAGED`：文档、分块和向量不写进注册定义正文。先发布知识版本，再在草稿版本上保存文档、配置访问策略、提交文件摄入或向量构建，然后发布该版本。
4. `REMOTE`：必须有受控 `endpoint`。`callbackProtocolVersion` 只能是 `1.0`。无版本的远程知识不能进入执行计划。带权限声明时，`mandatoryFilters` 必须包含 `SUBJECT`；过滤器只允许 `TENANT` 与 `SUBJECT`。
5. 把知识库写进智能体的 `allowedKnowledge` 或路由规则。重复的精确来源会被拒绝。
6. 回答出现引用后，用当前身份打开预览。预览会重新做历史和文档 ACL 检查，不重放工具。

## 配置

`topK` 是整数，1 到 10，省略为 3。它是知识定义上的条数，与智能体 `knowledgeRouting.topK`（1 到 50，省略为 8）不是同一个数。`tags` 可省略，最多 16 个不重复字符串，每项去空白后非空且最长 64。路由规则里的 `tags` 要和这里的标签一致才会按标签命中。`description` 可省略。某个来源没有路由规则时，`AUTO` / `ON_DEMAND` 用描述和这些标签与问题做词法匹配；得分为 0 的来源不会入选。空描述可以保存。

`chunking` 只能出现在 `MANAGED`。省略整个对象时，保存的策略是空对象，正文按 2000 个 UTF-16 字符、无重叠切开。写了 `chunking` 之后，未写的键按下表解释，这些缺省不会写回定义。

| 字段 | 类型与范围 | 省略时 | 怎么填 |
| --- | --- | --- | --- |
| `strategy` | `CHARACTER`、`PARAGRAPH`、`MARKDOWN` | `CHARACTER` | `CHARACTER` 按字符切，允许重叠。`PARAGRAPH` 与 `MARKDOWN` 的 `overlapChars` 必须是 0 |
| `maxChars` | 128 到 8192 | 2000 | 一块的最大字符数 |
| `overlapChars` | 0 到 `maxChars` 的一半 | 0 | 只在 `CHARACTER` 上使用 |
| `preserveParagraphs` | 布尔 | `CHARACTER` 为假，其余为真 | `CHARACTER` 不能设为真 |
| `preserveCodeBlocks` | 布尔 | 仅 `MARKDOWN` 为真 | 其他策略不能设为真 |

`retrieval` 也只能出现在 `MANAGED`。省略整个对象时策略是 `LEXICAL`。

| 字段 | 类型 | 何时必填 | 怎么填 |
| --- | --- | --- | --- |
| `strategy` | `LEXICAL`、`VECTOR`、`HYBRID` | 写了 `retrieval` 就必填 | `LEXICAL` 不能再带 `embedding` 或 `minScore` |
| `minScore` | 有限数字，-1 到 1 | 可省略，按 0 | 向量或混合检索的余弦下限 |
| `embedding` | 对象 | `VECTOR` 与 `HYBRID` 必填 | 端点走与工具相同的出站校验。见下表 |

`embedding`：

| 字段 | 类型 | 必填或默认 | 含义 |
| --- | --- | --- | --- |
| `endpoint` | 字符串 | 必填 | 嵌入服务地址。结构、HTTPS 和 origin 白名单与模型供应商相同 |
| `model` | 字符串，1 到 128 | 必填 | 嵌入请求里的 `model` |
| `spaceVersion` | 字符串，1 到 128 | 必填 | 向量空间标记，只含字母、数字、下划线、点和连字符。它和模型、维度一起进入空间摘要；摘要变化后，旧向量不再算当前空间，发布前要按新摘要重建 |
| `dimensions` | 整数，1 到 2048 | 必填 | 本地向量维度。请求默认不把维度发给服务 |
| `sendDimensions` | 布尔 | 可省略 | 只有 `true` 时，请求正文才附加 `dimensions` |
| `secretRef` | 字符串 | 可省略 | 与供应商相同：环境引用名或 `vault:` 凭据。省略则不附加 Bearer |

```json
{
  "description": "运维手册",
  "mode": "MANAGED",
  "topK": 5,
  "chunking": {
    "strategy": "MARKDOWN",
    "maxChars": 2000,
    "overlapChars": 0,
    "preserveCodeBlocks": true
  },
  "retrieval": {
    "strategy": "HYBRID",
    "minScore": 0.2,
    "embedding": {
      "endpoint": "https://embed.example.com/v1/embeddings",
      "model": "embed-small",
      "spaceVersion": "manual-2026-10",
      "dimensions": 1024,
      "sendDimensions": true,
      "secretRef": "EMBED_TOKEN"
    }
  }
}
```

`INLINE` 不写 `chunking` 或 `retrieval`。每篇文档要有非空 `id`，`text` 为 1 到 16384 个字符，文档数为 1 到 100。

其余运行配置：

| 项 | 当前值 | 说明 |
| --- | --- | --- |
| 文件格式 | `txt`、`md`、`pdf`、`docx`、`xlsx`、`pptx`、`png`、`jpg`、`jpeg` | 单份向量文档正文上限 4MiB |
| 解析器 | `SPARKTIDE_NODE_PARSER_JAVA`、`CLASSPATH`、`PLUGIN`、`TMPDIR` 四项同设或同空 | `CLASSPATH` 是绝对路径的 JSON 数组。部分配置会导致进程拒绝启动 |
| OCR | `SPARKTIDE_NODE_PARSER_OCR` 与 `SPARKTIDE_NODE_PARSER_OCR_LANGUAGES` | 默认镜像不安装 OCR。语言缺省为 `eng`。解析器不是操作系统沙箱 |
| 未配置解析器 | 上传与重试 | 返回 503 `CAPABILITY_UNAVAILABLE` |

访问策略保存后会推进 `knowledgeAccessEpoch`。已经固定旧 epoch 的运行、会话和预览会在服务端失败或要求新会话。历史正文不会被策略面板改写。

## 未装配的 5 个操作

下列操作在 `contracts/openapi.json` 中有说明，`apps/server` 没有对应路由，控制台也没有入口。调用不应被空结果伪装成成功。

| 操作 | 方法与路径 |
| --- | --- |
| `debugManagedKnowledge` | `POST /v1/apps/{app}/knowledge/{knowledgeId}/versions/{version}/retrieval-debug` |
| `evaluateManagedKnowledge` | `POST /v1/apps/{app}/knowledge/{knowledgeId}/evaluations` |
| `listKnowledgeEvaluations` | `GET /v1/apps/{app}/knowledge/{knowledgeId}/evaluations` |
| `getKnowledgeEvaluation` | `GET /v1/apps/{app}/knowledge/{knowledgeId}/evaluations/{evaluationId}` |
| `deleteKnowledgeEvaluation` | `DELETE /v1/apps/{app}/knowledge/{knowledgeId}/evaluations/{evaluationId}` |

这 5 项与「运维与评测」里的智能体质量门评测不是同一功能。后者会真实调用已配置模型，见 [用量与诊断](../控制台操作/用量与诊断.md)。

## 结果

- 引用事件 `reference.cited` 的 `kind` 为 `SYSTEM_DATA`、`KNOWLEDGE_DOCUMENT` 或 `WEB_RESOURCE`。
- 可带最多 1000 字的 `summary`、`capturedAt` 和 `previewAvailable`。链接可以省略。
- 知识片段预览返回 `CitationPreview`。被正文引用的成功 READ 工具可返回 `ToolReferencePreview`，`scope` 为 `TOOL_RESULT_SNAPSHOT`，只读当时结果。
- 平台管理身份没有业务正文旁路。原件下载会重新鉴权，并按附件返回。
