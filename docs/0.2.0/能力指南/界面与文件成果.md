# 界面与文件成果

界面能力分成两类：注册的交互界面，以及用户明确要求后生成的文件。普通回答、图表和会话摘要不会自动变成可下载文件。


## 范围

本文说明 GenUI 校验、问卷、平台 PDF 和业务文件引用。浏览器组件的集成方式见 [开发接入](../开发接入/README.md)。

## 步骤

1. 发布 `ui-capabilities`。`propsSchema` 必填，`fallback` 必须是非空文本。`interaction` 只能缺省、为 `null`，或为 `FORM` / `QUESTION`。
2. 需要结构化 GenUI 时，在 `propsSchema` 上显式设置 `$schema` 为 `http://json-schema.org/draft-07/schema#`，并带固定修订的 `x-sparktide-genui`。缺省方言的普通工具和业务 Context 不会因此改变。
3. 智能体通过 `allowedUi` 绑定界面。模型用 `select_ui_components` 按需加载所选节点的完整约束，而不是把所有约束都塞进每一轮。
4. 服务端校验通过后才产生 `ui.created`。校验失败把路径和约束交回 DSH，平台不自动重放工具。
5. 用户明确要求报告文件，且进程配置了 `SPARKTIDE_REPORT_FONT_FILE` 时，根智能体才注册 `generate_pdf_report`。
6. 下载平台 PDF 时走运行成果内容接口。每次都重新检查运行、业务和历史来源权限。

## 配置

`ui-capabilities` 的定义字段如下。`description` 可省略，省略时按空字符串交给模型。`propsSchema` 与 `fallback` 必填。`interaction` 可省略或为 `null`；要问卷或表单时才写 `FORM` 或 `QUESTION`。`permissions` 规则与智能体相同，可省略。

普通 `propsSchema` 使用受限方言，对象要 `additionalProperties: false`。需要 GenUI 公布子集时，再按步骤 2 显式写 `$schema` 和 `x-sparktide-genui`。模型档案的 `outputSchema` 不使用这套 GenUI 方言。

```json
{
  "description": "请用户确认工单号",
  "fallback": "请在业务页面确认工单号。",
  "interaction": "FORM",
  "propsSchema": {
    "type": "object",
    "additionalProperties": false,
    "properties": {
      "ticketId": { "type": "string", "minLength": 1, "maxLength": 64 }
    },
    "required": ["ticketId"]
  }
}
```

| 项 | 边界 |
| --- | --- |
| 新方言 | draft-07 的公布子集：本地 `#/definitions/` 引用、联合和条件。拒绝远程引用、未知关键词和嵌套 `$id`。Schema 深度 32、节点 10000、同值引用链 128 |
| 校验库 | `ajv@8.20.0`。不启用类型强转、默认填充、删字段或远程加载。服务端编译缓存 64 份 |
| 旧消息 | `2.x` 的字符串 `spec` 仍可读取。`3.0.0` 的 `spec` 是对象。回滚客户端时必须还能渲染已经写入的 3.0 消息 |
| 控制台问卷 | 只提交当前面板认识的字段。不认识的动态问卷不会伪造 JSON 答案 |
| PDF | PDFKit `0.20.2`。每文档最多 100000 个 JSON 字符、150 页、8MiB。单活渲染，最多 8 个排队任务。取消或超时会终止排版 |
| 字体 | 由部署方提供可读的中文字体文件，建议使用许可明确的字体。仓库不附带系统字体。未配置字体时不注册该工具 |
| 成果表 | 执行库格式 20 起的 `st_node_report_artifact`，按 `run_id` 与 `call_id` 幂等。当前初始化会把执行库升到 21，并保留该表 |
| 业务文件 | `storage=business`。平台不保存字节、不代抓 URL。`runId`、`conversationId`、`createdAt` 由平台绑定 |

PDF 协议不接受 HTML、脚本、外部 URL 或模型指定的磁盘路径。Word、Excel、PPT 不是当前成果类型。知识摄入用的办公文件只进入知识库，不会出现在成果列表。

## 结果

- 会话详情里的 `artifacts` 只包含真实文件成果。
- 平台 PDF 的内容接口最大返回 8MiB，`Content-Type` 为 `application/pdf`，`Cache-Control` 为 `no-store`。
- 业务网关使用同一路径去掉 `/v1/apps/{app}` 前缀。预览地址由接入方自己的存储和前端负责。
- 模型消息里的普通链接不能冒充文件成果。
- 厂商是否真正遵守全部 Schema 约束，需要在真实模型上单独验收。Schema 通过不等于业务数据正确。
