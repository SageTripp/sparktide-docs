# SDK 参考

查安装、方法、状态和兼容路径时使用本区。**第一次接入优先阅读[连续教程](../教程/README.md)**，这里不替代逐步操作。

| 要查什么 | 文档 |
| --- | --- |
| JVM 制品、Spring 开关、身份 SPI、标准 HTTP 与声明 | [业务后台 SDK（Java / Kotlin）](业务后台SDK.md) |
| JS/TS 安装、客户端认证、会话和事件方法 | [前端聊天 SDK](前端SDK.md) |
| 默认组件与 React / Vue 自定义状态层 | [React 与 Vue](React与Vue.md) |
| 已有工程的团队分工与交付参数 | [已有项目接入](接入流程.md) |
| 手工接入回调协议 / 非 Spring 服务 | [工具回调](工具回调.md) |
| 旧 AgentClient 等类型化调用 | [兼容客户端参考](业务接入/类型化聊天.md) |

能力对应的例子从[能力指南](../使用指南/README.md)进入。后台 SDK 与前端 SDK 是独立制品、职责不同，Java / Kotlin 共享 JVM 核心；React / Vue 共享前端协议与方法层。
