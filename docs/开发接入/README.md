# SDK 接入与参考

新接入先看[类型化注解与现有业务认证](SDK简化接入.md)：业务提供工具/知识和原有服务，SDK 管理模型适配、注册、认证传递、回调和聊天状态。本文所述新 API 使用内部开发候选，公开渠道仍是固定 0.1.0。

当前后端内部候选为 **0.1.1-auth.20261023-6**，新增原框架认证/权限、Origin/CORS 和错误协议自动装配；safeOps 1.2.1 接入已实质减少手写基建，真实三场景、原认证和浏览器恢复/退出均完成本机隔离候选验收。公开 0.1.0 不更新、不覆盖，详见[本轮范围](/产品支持/版本说明#基础设施下沉与业务服务复用)。

业务认证与数据权限继续由业务服务管理；普通 context、appId 和前端 identityKey 均不是可信身份。新接口与安全旁路需要配套更新双 SDK 和平台，不向旧下载链接填入未公开的候选包。
