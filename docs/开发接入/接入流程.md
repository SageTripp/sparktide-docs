# 已有项目怎样接入

在现有项目里，后台团队准备标准 `/api/ai`，前端团队通过 SDK 方法或 ChatPanel 调用它。**首次接入请先完成[连续教程](../教程/README.md)**，本页用来分配已有项目的工作。

## 后台团队要交付什么

1. 安装[业务后台 SDK](业务后台SDK.md)，声明模型和默认智能体。
2. 用现有登录认证生成 Principal，提供 `ChatCredentialResolver`；Cookie 认证同时接入 CSRF。
3. 开启 chat.enabled，发布业务 `/api/ai`；接口已由 Starter 封装，无需聊天 Controller。
4. 按需添加工具、知识和 PermissionProvider；受控发布配置。

向前端交付业务 API 前缀、Bearer / Cookie 登录方式、必要 CSRF 头、允许的部署域名和用户可用入口。**不交付底座管理凭据、模型 Key 或应用发布权限。**

对应实现：[模型与后台教程](../教程/接入后台.md)、[身份与权限](业务接入/业务权限与可信上下文.md)、[声明与发布](业务接入/声明式注册与启动发布.md)。

## 前端团队要交付什么

1. 安装[前端聊天 SDK](前端SDK.md)，客户端配置后台交付的 API 前缀和业务认证。
2. 先使用 React / Vue 的 ChatPanel 得到完整聊天页面；JS/TS 可直接调用 SDK 方法。
3. 用用户身份验证会话列表、发送、历史恢复、取消与必要确认。
4. 需要特定布局时再使用状态层，需要业务卡片时再注册 UI Renderer。

对应实现：[聊天页面教程](../教程/接入前端.md)、[React / Vue 定制](React与Vue.md)、[自定义 UI](../使用指南/界面组件.md)。

## 平台运维要交付什么

底座地址、应用初始化与凭据策略、模型 / 回调出站授权、密钥注入、HTTPS 与 SSE 代理、数据库与备份。初次部署从[部署与运维](../部署运维/README.md)进入；常规业务声明通过后台 SDK，控制台用于查看、调试和治理。

## 验收

先共同通过[第一轮对话检查](../教程/验证对话.md)，再按实际启用的工具、知识和身份能力执行[上线检查](../教程/接入生产.md)。前端刷新恢复同一会话；跨用户、租户与权限收回不会读到他人数据。
