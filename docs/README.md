# 把智能体接入你的业务

<p class="doc-lead">启澜是部署在自有基础设施中的智能体平台。用 SDK 连接模型、业务工具与知识，沿用已有登录和权限，让对话真正进入业务流程。</p>

<DocsPortal section="start" />

## 从第一轮对话开始

不必先读完所有参考文档。先用公开示例跑通一次对话，再决定如何接入自己的系统。

## 按技术栈接入

后台负责声明能力与复用业务认证，前端负责会话和交互。选择与你的应用匹配的入口。
