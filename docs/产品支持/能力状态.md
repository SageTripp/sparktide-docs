# 能力状态

本页回答一个具体问题：某项能力**现在能不能用**、用到什么程度、还缺什么。它对应 0.1 发布线；发行渠道于 2026-10-09 核对，其余能力保留已有隔离验收口径。

状态口径只有四种，含义如下：

| 状态 | 含义 |
| --- | --- |
| 已实现（本地验证） | 在本机隔离环境与自动化测试中通过；**不等于**真实供应商、真实业务系统或生产容量验收 |
| 已实现（需实网验证） | 代码路径就绪，但缺少真实外部条件，尚无实网证据 |
| 部分实现 | 只覆盖一部分，缺什么见“还不能做什么” |
| 未实现 | 目前不可用，不要按可用来规划 |

## 还不能做什么

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 通知精确一次送达 | 部分实现 | 持久投递与退避已实现，但发送成功后、标记成功前退出会重复投递；接收端需按告警编号与状态幂等 |
| 拒绝信号的完整审计级记录 | 部分实现 | 拒绝信号按应用×分钟聚合，且先在内存计数后周期落库；崩溃最多丢一个刷新周期，不能当作逐条审计 |
| 脱敏对实时运行与事件读取生效 | 部分实现 | 脱敏只覆盖治理输出（审计查询/导出与归档导出），实时运行与事件读取仍由权限与字段白名单保护 |
| 留存与脱敏的按应用配置 | 部分实现 | 两者都是平台级单条策略，所有应用共享同一组规则 |
| 模型语义评分（用评审模型判断回答质量） | 未实现 | 评测目前只有确定性规则断言与人工评分 |
| 评测容量与并发基线 | 未实现 | 评测为单线程顺序执行，未做容量测量 |
| 屏幕阅读器朗读与真实窗口缩放 | 未实现 | 已程序化检查可访问名称、对比度、键盘焦点与 200% 等效视口，减少动效也已在控制台和文档站首页测过；仍未用屏幕阅读器实测，也未在真实窗口做 200% 缩放 |
| 任意步骤透明续跑 | 未实现 | 失联任务明确失败，不重放未知副作用 |
| 生产高可用、TLS、容量与恢复时间 | 未实现 | 需要域名证书、目标主机与容量指标；已有的恢复演练与容量基线只覆盖单机容器与极小数据量 |
| 公开制品与安装包发布 | 已实现 | 0.1.0 提供公开 Maven、前端 tgz、底座 Jar 与 GHCR 镜像；匿名下载及校验通过，源码仓库保持私有；许可证与商业支持由维护者补充 |

## 如何核对

本页状态来自平台仓库的验证记录与隔离验收，区分“本地验证”和“实网验证”。平台内部的完整矩阵（含每行证据与限制）位于平台仓库 `docs/项目管理/能力状态矩阵.md`；本页是面向使用者的同一口径摘要。

2026-10-08 最终本地链：平台 333 项、新 PostgreSQL 133 项、后台 SDK 115 项、前端 37 项、控制台 16 项全部通过；四种已安装消费者和真实 Chrome 会话管理通过。单实例零延迟模型夹具的 8 路聊天 P95 352.53ms、26.99 成功 runs/s，读取以 5 万合成行测量，各预声明门禁通过。全局事务围栏保留，以上不代表真实供应商、生产容量、许可证或公开发布已完成；正式上线条件仍缺。

任何“已实现”“完整落地”的说法都应与本页一致。本页未列出的能力视为未实现，不要按可用来规划。
