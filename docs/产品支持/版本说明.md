# 版本说明与兼容性

本手册对应 0.1 发布线，最近核对日期为 2026-10-07。页面描述的是已有实现与可执行使用方式；某项能力当前是否可用、验证到什么程度、还缺什么，一律见[能力状态](./能力状态.md)。公开发行标签见[版本与获取](../开始使用/版本与获取.md)。

## 当前版本能力

- 应用、用户和租户作用域，管理凭据与 OIDC 访问令牌。
- 八类能力资源的草稿、发布、撤销和默认智能体。
- 模型注册、应用绑定、原生流式响应和配置价目统计。
- 工具调用、危险操作审批、知识引用、子智能体和 UI 协商。
- 会话、幂等、取消、超时、事件重放与运行审计。
- 托管文本知识、向量与混合检索、文件摄入（含 OCR）、远程租约、PostgreSQL 多实例协调与归档。
- 调用链与运行指标：W3C 关联、父子节点计时、首字耗时、Prometheus 指标与可选 OTLP 导出。
- 告警规则、去重、抑制、确认、恢复、运维状态工作台与持久通知投递。
- 智能体评测（确定性规则断言与人工评分）与发布门禁。
- Java、Kotlin、TypeScript、React、Vue 接入能力，以及四类可运行示例工程。

## 稳定契约

HTTP 路由使用 `/v1`；事件 protocolVersion 为 `1.0`。能力资源使用三段精确版本。SDK 软件版本、资源版本、HTTP 版本和事件版本是四个不同概念。

本地制品版本：平台/后台 SDK `0.1.0-SNAPSHOT`、前端 SDK `0.1.0`。还未提供的公开分发信息以占位形式展示，不伪造 Release 或公开包链接。

## 运行约束

| 主题 | 当前行为 |
| --- | --- |
| 执行恢复 | 持久状态与事件重放；失联任务明确终结，不透明重跑副作用 |
| 知识 | 托管文档与原件摄入、词项/向量/混合检索，以及 REMOTE 外部知识；容量与格式边界见知识接入指南 |
| Schema | 受限 JSON Schema 方言，不执行远端引用 |
| 费用 | 配置价目估算，缺失用量或价格时未知 |
| 扩容 | 同库多实例协调，容量需按业务压测 |
| 身份 | 本地凭据与 RS256 OIDC 访问令牌；不提供账户密码注册 UI |

## 升级兼容性

升级前记录数据库迁移、SDK 与业务能力版本。新字段和协议能力需要前后端共同验证，不能只更新文档或一侧 SDK。数据库回滚遵循[升级与备份](../部署运维/升级与备份.md)。

## 控制台与文档更新

当前本地制品提供六模块工作台、模块内导航与总览、知识中心独立工作区、浅深色主题、窄屏菜单和带应用作用域的页面书签。产品文档同步提供 [控制台使用指南](../使用指南/控制台/README.md) 和实际界面截图。HTTP `/v1` 与事件 `1.0` 契约保持兼容；升级服务镜像或 Jar 后刷新浏览器即可使用新界面。本条描述本地已实现能力，公开发行标签仍以 [版本与获取](../开始使用/版本与获取.md) 为准。

## 2026-10-03 运行观测

加入异步保存的父子调用链、W3C 跨服务关联、Java 线程池与 Kotlin 协程传播、前端类型化查询、独立 Prometheus 指标及可选 OTLP/HTTP JSON 出口。运行中心增加观测页和调用链抽屉。配置、抽样、保留和权限见[使用说明](../部署运维/可观测性与调用链.md)。
