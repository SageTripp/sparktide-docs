## 学習建议

第一轮对话只需要默认智能体。接入业务时通常先增加一个 READ 工具，再增加知识 Provider，最后接正式权限与发布策略。

UI 卡片、子智能体、向量索引、多候选路由和费用账本都是按需扩展。它们不会因为安装 SDK 自动成为你的业务能力，也不应该阻挡最小聊天接入。

## 代码、控制台与参考各用在哪里

模型、智能体和业务能力优先通过后台 SDK 声明；普通聊天通过前端 SDK。专题中的 JSON 用来解释 Registry 字段，手工注册用于已有系统或治理场景，不要求在管理平台逐项照抄。

控制台操作从[独立操作手册](控制台/README.md)进入，底层 HTTP 与兼容接口查[接口参考](../接口参考/README.md)。
