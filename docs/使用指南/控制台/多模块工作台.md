# 工作区与日常操作

控制台按应用组织日常工作。登录后默认进入总览：首次使用先创建应用，日常使用先选择应用，再维护配置或排查运行问题。

## 工作区导航

| 范围 | 入口 | 用途 |
| --- | --- | --- |
| 全部应用 | 总览 | 查看应用状态、平台状态与各应用待处理告警 |
| 全部应用 | 应用管理 | 按名称、ID 和状态查找应用，进入配置、运行记录或设置 |
| 当前应用 | 应用配置 | 维护应用信息、模型、智能体、工具、知识与发布版本 |
| 当前应用 | 运行记录 | 查询运行、查看调用链、模型调用与工具执行 |
| 当前应用 | 告警 | 处理当前应用的告警，维护告警规则 |
| 当前应用 | 操作记录 | 追溯该应用的配置变更与管理操作 |
| 平台 | 平台设置 | 管理共享模型、服务状态、数据保留与脱敏 |

顶部标题栏依次排列 SparkTide、应用选择器与创建按钮，以及**总览 / 应用管理 / 平台设置**。**创建应用**与**平台设置**仅平台管理员可见。未选择应用时隐藏应用导航；选择后显示该应用的总览、配置、运行记录、告警和操作记录。

## 个人信息与外观

标题栏最右侧提供帮助、主题图标和用户头像。点击头像可查看显示名称、角色与应用范围，打开**个人信息**或**退出登录**。

个人信息中可以修改显示名称和头像颜色，保存后同一身份再次登录时继续使用。用户标识、角色、应用范围和租户由登录身份决定，只能查看。若多人共用同一平台管理员凭据，会使用同一份展示资料。

主题图标在深色与浅色之间切换，设置保存在当前浏览器。

## 首次创建应用

1. 登录控制台，在总览或应用选择器旁点击**创建应用**。
2. 填写名称和应用 ID。名称支持 1–128 个字符；ID 以小写字母开头，支持小写字母、数字和连字符，最长 64 个字符，创建后不可修改；`global` 为保留值。
3. 创建成功后，控制台自动选中新应用并进入应用配置。
4. 由平台管理员准备访问凭据，在业务项目中配置应用 ID、平台地址和凭据，再接入 SDK。
5. 完成资源配置、发布和业务验证后，设置默认智能体。创建应用本身不会启用智能体运行。

完整步骤见[应用接入教程](../../教程/README.md)。已由初始化脚本创建的应用可以直接选择，无需再次创建。

## 应用管理

**应用管理**列出当前身份可访问的应用。可以同时按名称或 ID 搜索、按状态筛选。列表显示应用 ID、状态和默认智能体。

- 点击应用名称进入该应用总览。
- 点击**配置**查看应用内全部配置项及版本来源。
- 点击**运行记录**查询该应用的调用历史。
- 点击**设置**维护名称、启用状态、业务权限和可信上下文服务。

停用或归档需要填写变更原因；修改设置时服务器检查修订号。归档保留历史数据，恢复启用需具备可用的默认智能体。

## 日常监控

1. 打开控制台总览。平台管理员在“全部应用”范围查看平台服务和各应用待处理告警。
2. 从应用选择器或应用列表进入一个应用，查看累计运行、进行中、失败与超时、等待确认数量。
3. 在最近运行中打开需要排查的记录，查看状态、错误和调用链。
4. 处理该应用的告警，或进入应用配置检查相关参数与版本。

切换应用会回到该应用总览；选择“全部应用”返回全局总览。平台管理员进入应用后，运行和告警同样限定在当前应用内。

运行统计为该应用累计值。总览中的告警从最近加载的记录中筛选，页面标明加载范围；没有待处理告警不代表外部服务均可用。

## 查询与排查运行

选择应用后，在**运行记录**设置条件并点击“查询”：

| 条件 | 用法 |
| --- | --- |
| 运行 ID | 输入完整标识，精确匹配 |
| 状态 | 选择运行中、失败、超时、待用户确认等状态 |
| 时间范围 | 最近 24 小时、7 天、30 天，或全部时间 |

筛选在服务器分页前执行。分页按开始时间从新到旧排列；刷新重新读取当前条件，重置恢复最近 24 小时和全部状态。

打开运行详情后按需要选择：

| 详情页签 | 排查内容 |
| --- | --- |
| 概览 | 状态、开始时间、耗时、错误代码及关联编号 |
| 调用链 | 各执行环节耗时与错误，定位模型、工具和检索节点 |
| 模型调用 | 调用状态、用量、费用与待核对记录 |
| 工具执行 | 业务执行状态与结果未知的核对流程 |
| 输出与引用 | 智能体结果和回答来源；业务正文需运行所有者授权 |

运行详情可直接进入智能体和模型配置，核对运行使用的版本。

调用链未采样或超过保留时间时可能没有节点，可以继续查看执行与审计记录。运行详情中的“待用户确认”需要由业务用户在原客户端处理。

## 处理告警

1. 在**告警**打开问题，核对应用、规则、当前值与最近触发时间。
2. 点击**接手告警**并填写处理说明，停止该告警的重复通知。状态变为“处理中”。
3. 根据处理建议进入运行、模型授权或预算页面定位原因，完成修复。
4. 验证问题已解决后，点击**标记已恢复**并填写恢复说明。

接手表示有人跟进，不表示服务已经恢复。告警条件为应用级聚合；具体任务应在该应用的运行或执行记录中查询。

遇到工具执行结果未知时，先使用执行标识查询业务系统，再在工具执行记录中登记结果和依据。核对只更新账本，不重复执行业务操作。

告警列表按最近触发时间分页，严重程度排序和状态筛选适用于当前页。

## 维护资源与版本

在**应用配置**查看各配置项的版本数、SDK 与平台管理数量、已发布数量，再进入具体资源列表。

资源列表统一展示标识、版本、发布状态、管理方式与可用操作。使用关键词与状态筛选定位资源。

- **SDK 管理**：在业务代码中修改，重新注册和发布。平台保留来源信息。
- **平台管理**：可以编辑草稿；发布后通过新版本变更配置。
- **发布与启用**：发布版本和切换默认入口是独立操作。在发布管理中检查依赖并核对发布结果。
- **模型授权**：应用只能使用已授权模型。共享模型的应用授权由平台管理员完成。

知识文档、导入任务、索引和检索测试对应具体知识库版本。变更内容前确认所选应用和版本。

## 帮助、主题与书签

标题栏的**帮助**按操作任务提供步骤与排障建议，并包含当前权限可访问的相关入口。深浅色主题通过页头切换；窄屏通过“菜单”展开导航，表格在容器内滚动。

页面地址可以作为书签保存，例如 `#/runtime/activity?app=customer-service`。重新登录时会检查身份和应用权限后恢复入口；旧页面地址继续可用。地址不包含访问凭据。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 没有运行记录 | 检查应用与时间范围，确认完整运行 ID；也可选择“全部时间” |
| 看不到共享模型或访问凭据 | 核对平台管理员权限 |
| 页面无法加载 | 检查服务与凭据，点击“重试”；凭据失效时重新登录 |
| 更新源码后仍是旧界面 | 更新实际运行的服务 Jar 或镜像，再刷新页面 |
| 无法读取业务输出 | 使用运行所有者的业务凭据；管理员权限不替代业务身份 |

进一步排障见[监控与排障](../../部署运维/监控与排障.md)，变更追溯见[审计查询、导出与留存](../../开发接入/运维治理/审计查询导出与留存.md)。
