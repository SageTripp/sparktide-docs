# 多模块工作台

启澜控制台将平台管理划分为七个工作模块。顶部选择业务模块，左侧选择当前应用与模块内任务，主区域显示实际数据，详情和配置在右侧抽屉中处理。

![启澜多模块控制台](/images/控制台工作台.png)

截图使用隔离环境中的示例应用与实际记录。你的资源数量、费用和运行结果以自己部署的平台为准。

## 连接你的平台

1. 打开部署地址下的 `/console/index.html`；生产环境先配置 [HTTPS 与网关](../../部署运维/HTTPS与网关.md)。
2. 输入平台管理员或应用管理员凭据，点击“连接平台”。业务用户通过自己的聊天客户端接入。
3. 在左侧“工作空间”选择应用。所有应用资源页面、统计、知识版本与运行记录跟随这个选择。
4. 选择顶部模块，进入模块总览，再从卡片或左侧菜单进入具体操作。

访问凭据只存在本次页面内存。刷新或关闭页面后需要重新连接；书签不会保存凭据。平台管理员可以管理全部授权范围，应用管理员只进入自己有权访问的应用。公共模型和访问凭据管理仅向平台管理员展示；最终权限仍由服务端检查。

## 七个工作模块

| 模块 | 模块内入口 | 适合完成的任务 |
| --- | --- | --- |
| 工作台 | 应用概览 | 查看默认智能体、能力、累计运行和配置费用；进入其他工作模块 |
| 智能体与能力 | 能力总览、智能体、工具、界面能力、发布管理、智能体评测 | 编辑草稿、检查模型兼容性、配置能力授权、发布完整批次、切换默认智能体、运行评测与查看逐例断言 |
| 知识中心 | 知识总览、知识库、托管文档、文件摄入、向量索引、检索与评测 | 管理知识版本，摄入文件和文档，构建索引、调试检索并比较版本 |
| 模型中心 | 模型总览、模型供应商、模型、模型绑定、模型配置、公共供应商、公共模型 | 接入模型、授权应用、配置价目与候选路由，查看绑定健康与受限探测 |
| 运行中心 | 运行总览、运行调试、运行记录、运行观测、告警管理、运维状态 | 发起实际对话，处理确认、取消、父子任务和结果，查看运行状态分布、调用链与告警，核对实例级依赖链 |
| 应用治理 | 治理总览、配额与预算、访问凭据、审计记录 | 修改应用和业务接入配置、管理费用额度与凭据、筛选审计历史和导出 |
| 平台运维 | 数据留存、输出脱敏 | 按类别配置留存策略与到期清理，配置治理输出的脱敏规则；仅平台管理员可见 |

总览展示服务器返回的当前应用数据。模型中心的资源总数同时包含当前应用模型资源，以及平台管理员可见的公共模型资源。运行成功率按累计运行计算；没有运行时显示“—”。配置费用依据版本价目与用量计算，不代表供应商账单。

## 首次建立业务应用

1. 在**工作台 → 应用概览**创建应用；先确认应用标识和业务名称。
2. 在**模型中心**创建并发布供应商和模型，建立应用绑定，再发布模型配置。详见 [模型接入](../模型接入.md)。
3. 在**智能体与能力**配置工具和界面能力；在**知识中心**准备需要使用的知识。详见 [业务工具](../业务工具.md)、[知识库](../知识库.md)、[界面组件](../界面组件.md)。
4. 创建智能体草稿，引用已经发布的精确能力版本，检查模型兼容性与预算。通过 [批次发布](../批次发布.md) 预检依赖并发布，设置默认入口。
5. 在**运行中心 → 运行调试**使用正确业务身份发送消息，核对回答、引用、组件、审批和终态。
6. 在**应用治理**配置业务权限与可信上下文、额度与预算，再按 [开发接入](../../开发接入/接入流程.md) 将智能体加入你的产品。

## 使用知识工作区

![知识中心的独立工作区](/images/控制台知识中心.png)

知识库入口支持内联、托管和外部知识定义。文档、文件、索引及检索评测工作区只列出尚未撤销的 **MANAGED 托管知识版本**。

1. 在“知识库”创建或选择托管版本。资源卡片上的“文档、文件、索引、检索评测”可直接进入相应版本的工作区。
2. 在工作区顶部的“精确知识库版本”选择 `标识 · 版本 · 状态`。同一个知识库的各个版本分别管理文档和索引。
3. 在“托管文档”导入文本、查看正文与分块、编辑文档访问控制或执行有界批量维护。详见 [文档权限](../文档权限.md)。
4. 在“文件摄入”上传支持的原始文件，查看解析状态、失败说明与任务对应的文档版本。详见 [文件上传、解析与摄入任务](../../开发接入/知识接入/文件上传解析与摄入任务.md)。
5. 在“向量索引”检查当前版本的策略和索引。LEXICAL 版本显示词项索引说明；VECTOR / HYBRID 版本可在草稿中构建或重建向量并查看任务与健康状态。详见 [向量与混合检索](../../开发接入/知识接入/向量与混合检索.md)。
6. 在“检索与评测”按当前身份调试检索、对比版本和查看自己的评测历史。详见 [知识检索调试与版本评测](../../开发接入/知识接入/知识检索调试与版本评测.md)。

已经发布的版本保持只读。发布前核对文档访问范围、索引与检索结果；修改内容应创建新草稿版本。切换工作区会保留本次页面选中的知识版本；切换应用会清除该选择。刷新后重新连接，优先选当前应用的首个草稿版本，否则选择首个可用发布版本，**不会自动恢复上次知识版本**。操作前始终核对顶部版本。

## 详情、帮助与主题

- **右侧抽屉**：编辑资源、查看模型兼容性、模型健康、运行详情和审计元数据。表单错误保留在抽屉中，修正后重新保存；关闭前保存所需修改。
- **使用帮助**：当前页面右上角展示当前模块的功能入口，适合快速找到相关任务。本页及领域指南提供完整步骤。
- **浅深色主题**：顶部“深色主题 / 浅色主题”切换。首次遵循系统偏好，手动选择只在当前浏览器的控制台中保存；文档站可以独立设置主题。两者使用相同的蓝色品牌和浅灰/深灰背景。
- **窄屏操作**：顶部模块导航可横向滚动，“模块菜单”展开当前模块侧栏。表格可在表格内部横向滚动，配置抽屉占满窄屏。

## 书签与返回

模块页面地址采用 `#/模块/入口?app=应用标识`，例如：

```text
/console/index.html#/knowledge/knowledge-documents?app=monitor-app
/console/index.html#/runtime/chat?app=monitor-app
```

可保存为书签或使用浏览器后退/前进。重新连接后，平台核对你的身份和可访问应用，再恢复对应入口。未知模块、非法参数和没有权限的应用会返回可访问的工作空间。旧地址 `#overview`、`#knowledge` 等继续可用。地址中不要添加凭据、用户身份或正文。

## 出现问题时

| 现象 | 处理方式 |
| --- | --- |
| 工作空间没有应用 | 平台管理员先创建应用；应用管理员核对凭据的应用范围 |
| 看不到公共模型或访问凭据 | 核对是否使用平台管理员；应用管理员没有这些平台入口 |
| 知识工作区为空 | 创建 MANAGED 托管版本，或在知识库入口管理 INLINE / REMOTE 定义；撤销版本不参与工作区选择 |
| 操作的知识版本与预期不同 | 检查应用和顶部精确版本，特别是在刷新或切换应用之后 |
| 页面提示暂时无法加载 | 核对服务连通性、凭据权限和应用状态，再使用“重新加载”；刷新后需要重新连接 |
| 升级后仍是旧界面 | 更新实际运行的服务镜像或 Jar，再刷新页面；只更新源码不会替换已运行制品 |

部署排障见 [监控与排障](../../部署运维/监控与排障.md)，运行与审批语义见 [运行与审计](../运行与审计.md)，管理操作追溯见 [审计查询、导出与留存](../../开发接入/运维治理/审计查询导出与留存.md)。

## 运行观测与调用链

在“运行中心 → 运行观测”查看实际节点的延迟分布、错误与采集状态；在“运行记录 → 详情 → 查看调用链”追踪一次运行中的父子节点。指标含义、保留窗口和 Collector 接入见[可观测性与调用链](../../部署运维/可观测性与调用链.md)。
