# 创建、发布与协作智能体

业务接入默认通过后台 SDK 声明与发布，见 [业务后台 SDK](../开发接入/业务后台SDK.md)。以下管理流程用于查看、调试及显式治理；代码声明的资源显示来源，不能从管理页无痕修改。

智能体将系统提示词、模型配置和允许使用的能力组合成一个可发布版本。配置应从业务职责出发，明确能做什么、使用哪些数据、哪些操作需要用户确认。

## 创建基本智能体

后台用 ModelDeclarations.agent 声明提示词、模型配置和工具 / 知识引用，完整例子见[后台教程](../教程/接入后台.md)。下面是进阶字段参考；按需要添加到版本化定义，使用 RegistrationManifest 统一注册发布：

```json
{
  "systemPrompt": "你是订单服务助手。先查询授权数据，信息不足时说明，不编造订单状态。",
  "modelProfile": {"id":"balanced","version":"1.0.0"},
  "allowedTools": [{"id":"order-lookup","version":"1.0.0"}],
  "allowedKnowledge": [],
  "allowedAgents": [],
  "allowedUi": [],
  "delegatedCapabilities": [],
  "limits": {"maxSteps":8,"maxToolCalls":16,"maxAgentCalls":8,"maxDepth":3,"maxBudgetUnits":32000,"timeoutSeconds":120}
}
```

清单预检确认模型配置和 order-lookup 依赖可发布，受控批次发布智能体；保存草稿不会自动启用该版本。默认入口通过 SDK 的 defaultAgent 或受控发布设置。显式指定非默认版本时，聊天请求同时提供 `agentId` 和 `agentVersion`。

## 授权能力

允许列表只填写完成职责所需的精确版本。不在列表中的工具、知识、子 Agent 和 UI 不会因为提示词请求而获得授权。工具还会校验业务角色和输入输出 Schema。

知识内容、模型输出和前端 context 都不是授权来源。业务工具必须根据回调中的可信身份再次判断数据访问权限。

## 预算与超时

在智能体定义中配置模型尝试、函数调用、子调用、深度、字符、超时、供应商 Token 和金额额度。根任务覆盖全部父子消耗，子定义形成独立预留；子调用结束返还未用容量。旧 maxTokens 为字符别名，新配置用 maxBudgetUnits，不能同时填写。

供应商 Token 与费用需在发送前保守预留，完整终结回执后实际结算。子调用一旦超时立即停止网络与审批等待，不延长根时限。详见[父子智能体额度与结果](../开发接入/运行时/父子智能体额度与结果.md)。

## 让主智能体委派任务

先发布子智能体，例如 `order-specialist / 1.0.0`。在主智能体中加入：

```json
{
  "allowedAgents": [{"id":"order-specialist","version":"1.0.0"}],
  "delegatedCapabilities": ["tools/order-lookup@1.0.0"]
}
```

以上字段合并到完整 definition，不能替代必填的提示词与模型配置。授权上限应覆盖子智能体及后代所需的工具、知识和 UI；发布时验证无环和授权边界。子智能体内部文本不会直接作为主回复流泄漏给用户。

## 版本更新与回退

在代码中创建新语义版本 → 修改和预检 → 显式发布 → 切换默认。回退默认入口时选仍处于 PUBLISHED 的旧版本。已撤销版本不可重新发布，需要另建版本。撤销运行依赖可能使后续调用失败，先安排入口迁移。
