# 从零接入一个业务助手

这是一条连续教程：使用业务后台 SDK 声明模型和智能体，前端 SDK 调用业务后台，最后得到一个可以发送消息、查看历史的聊天页面。先完成纯文本对话，再按需加入业务工具、知识和正式认证。

**第一次接入从第 1 步开始，依次完成第 5 步。** 已有项目可以复用教程中的声明、身份适配和前端组件；不要把教程的本地身份方案带到生产。

## 最终会得到什么

```text
浏览器（React / Vue，127.0.0.1:5173）
  └─ 前端 SDK → /api/ai（开发代理）
       └─ 业务后台（Spring，127.0.0.1:8091）
            ├─ 业务认证 + 后台 SDK 标准 HTTP API
            └─ 底座（127.0.0.1:8080）→ 你选择的模型服务
```

底座保存会话、消息、运行和事件；后台 SDK 接入业务能力、适配用户身份并提供 HTTP API；前端 SDK 提供方法与聊天组件。浏览器无需知道底座地址、appId 或管理凭据，也不用再写一套 fetch / SSE 包装。

## 按顺序完成

| 步骤 | 你要做的事 | 完成标志 |
| --- | --- | --- |
| [1. 准备环境与制品](准备环境.md) | 下载公开 SDK 和底座 Jar，准备实际模型并启动底座 | 健康检查 UP，公开制品可获取 |
| [2. 创建应用与开发身份](创建应用.md) | 一次性创建 tutorial 应用，分离应用管理、USER 和浏览器业务令牌 | 初始化命令完成，不在浏览器放平台凭据 |
| [3. 声明模型并启动后台](接入后台.md) | 用清单声明模型图、提供身份解析，开启标准聊天 HTTP API | 已登录请求返回空会话列表 |
| [4. 接入聊天页面](接入前端.md) | React / Vue 二选一，使用 SDK ChatPanel | 看见会话列表和发送框 |
| [5. 验证第一轮对话](验证对话.md) | 发送消息、追问、刷新历史，定位常见错误 | Run 成功，历史保持同一会话 |
| [6. 添加工具与知识](添加工具与知识.md) | 可选：在后台声明业务工具和知识 Provider | 得到实际工具数据和知识引用 |
| [7. 接入业务登录并上线](接入生产.md) | 替换本地身份，显式发布并配置部署 | 业务身份、模型和上线检查通过 |

## 使用完整示例

[下载入门示例 ZIP](/downloads/sparktide-tutorial.zip)。压缩包含后台完整源码、Gradle Wrapper、React / Vue 两个前端、配置生成与加载脚本。**SDK 制品和模型密钥需自己准备**，第 1 步给出获取命令。

教程命令以 **Windows PowerShell 7、同一机器上的独立开发环境** 为基准。已部署的底座可复用，但地址、应用授权及密钥注入必须由该环境管理员确认；不要覆盖已有环境。

Java / Kotlin 的共享原理只讲一次，语言差异在标签页展示。前端框架也采用标签页，**同一组中选择一个版本**，按步骤顺序执行命令。

## 什么时候深入

能完成第 5 步之后，再从[能力指南](../使用指南/README.md)选择一项业务需求。排查某个参数时查[SDK 参考](../开发接入/README.md)，需要自己实现客户端或回调协议时查[HTTP API 与事件](../接口参考/README.md)。管理平台的查看、调试和治理在[控制台操作](../使用指南/控制台/README.md)。
