# 产品概览

SparkTide 是部署在自有基础设施中的智能体平台。平台统一管理应用、会话、资源版本和执行过程，业务系统通过 SDK 接入模型、工具、知识与用户权限。

## 产品组成

| 组成 | 主要职责 | 使用者 |
| --- | --- | --- |
| 平台服务 | 资源与版本、会话、运行执行、授权检查和事件流 | 平台运维与业务服务 |
| 后端 SDK | 声明业务能力，适配用户身份，提供业务调用与回调 | Java / Kotlin 开发者 |
| 前端 SDK | 消息、会话、流式状态、确认与界面组件 | JS / TS、React / Vue 开发者 |
| 管理控制台 | 平台授权、运行监控、问题处理与维护 | 平台管理员与应用管理员 |

推荐调用链路为**浏览器 → 业务后端 → 平台服务**。业务后端复用现有登录和授权，前端无需持有平台管理员凭据或模型密钥。

## 业务接入与平台管理

开发者在业务项目声明工具、知识、模型调用配置和智能体，通过 SDK 注册与发布版本。控制台展示相同的资源，帮助运维人员检查连接、处理故障与追溯变更。

平台管理员创建应用并准备初始访问凭据，管理共享模型授权。应用管理员在授权范围内维护资源、预算和运行配置。业务用户通过原产品使用智能体。

## 核心对象

| 对象 | 含义 |
| --- | --- |
| 应用 | 独立业务产品的资源与权限范围 |
| 智能体 | 版本化的提示词、模型调用配置与能力列表 |
| 会话 | 一组连续的用户与智能体消息 |
| 运行 | 一次消息产生的执行过程，包含状态、调用与结果 |
| 资源版本 | 智能体依赖的模型、工具、知识或界面定义版本 |
