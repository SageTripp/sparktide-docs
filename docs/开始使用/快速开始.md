# 快速开始

第一次接入请进入[从零接入一个业务助手](../教程/README.md)。新版教程按文件和命令连续展开，包含完整示例与每一步的检查点。

1. [准备环境与 SDK 制品](../教程/准备环境.md)：启动底座并准备实际模型。
2. [创建应用与开发身份](../教程/创建应用.md)：独立初始化，不把管理凭据放进浏览器。
3. [声明模型并启动后台](../教程/接入后台.md)：Spring Starter 提供标准聊天 API。
4. [接入聊天页面](../教程/接入前端.md)：选择 React / Vue，直接使用 ChatPanel。
5. [验证第一轮对话](../教程/验证对话.md)：回答、续接和刷新历史。

已有业务可直接复用步骤 3 和 4 的配置与代码。跑通后再[添加工具与知识](../教程/添加工具与知识.md)，正式登录和发布见[接入生产](../教程/接入生产.md)。
