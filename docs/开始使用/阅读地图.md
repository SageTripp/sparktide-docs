第一次接入只需沿着 **准备 → 应用 → 后台 → 前端 → 验证** 这条路线读。跑通之后，再根据业务需求选择能力专题。

## 文档分为三层

**教程**按步骤给出完整文件、命令、预期结果和失败排查。不要把语言或框架标签理解为都要执行；每组选择一个。

**能力指南**按业务需求解释概念、接入方式和限制，例如模型、工具、知识、UI、权限与发布。每页说明适用阶段，再链接到更深的协议和 SDK 用法。

**参考与运维**用于按需查询参数和部署治理，不是接入的前置阅读清单。底层 HTTP、旧直连客户端、手工 Registry 注册放在参考中，常规业务优先使用双 SDK。

## 接入过程中不需要先做什么

默认 ChatPanel 已能发送消息、展示历史和处理确认。第一轮聊天只需要应用、模型图、业务身份适配和前端客户端；自定义卡片、子智能体、向量检索、多实例与审计导出均可在接入后按需学习。

管理平台用于查看、调试、停用和治理。业务模型、工具、知识与智能体的常规声明尽量由后台 SDK 管理，不要求从控制台逐个录入。
