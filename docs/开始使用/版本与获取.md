# 版本、源码与安装方式

本手册以当前源码发布线为依据。依赖版本必须与实际取得的软件一致，不要把 HTTP 协议版本当作 Maven 或 npm 包版本。

## 版本矩阵

| 组件 | 当前版本 | 使用环境 |
| --- | --- | --- |
| 平台 | 0.1.0-SNAPSHOT | JDK 17；生产 PostgreSQL 17 |
| Java SDK | dev.sparktide:sdk-java:0.1.0-SNAPSHOT | Java 17 或兼容 JVM |
| Kotlin SDK | dev.sparktide:sdk-kotlin:0.1.0-SNAPSHOT | JDK 17；源码使用 Kotlin 2.3.20 |
| 前端 SDK | @sparktide/frontend-sdk 0.1.0 | ESM；构建环境 Node.js 22 |
| React / Vue 适配 | 随前端 SDK | React 18–19；Vue 3.5 |
| HTTP / 事件 | /v1 / 1.0 | JSON、HTTP、SSE |
| 文档站 | VitePress 1.6.4 | Node.js 22/24；静态部署 |

## 获取源码

公开仓库地址：**待补充**。取得发布方提供的源码包后，使用下面的仓库名称对应文档命令：

```text
sparktide-platform/
sparktide-backend-sdk/
sparktide-frontend-sdk/
```

命令中的“项目根目录”指相应仓库，不是整个工作区。本文档不依赖开发者个人机器上的绝对路径。

## 当前可执行的安装方式

- 平台：从源码构建 Jar，再使用仓库 Dockerfile/Compose 部署，或独立运行 Jar。
- 后台 SDK：构建并发布到 Maven Local，或由组织发布到自己的 Maven 仓库。
- 前端 SDK：构建后 `npm pack`，在业务工程安装生成的 `.tgz`；也可按组织流程发布到私有包仓库。

详细命令见[业务后台 SDK](../开发接入/业务后台SDK.md)、[前端 SDK](../开发接入/前端SDK.md)。

## 公开分发信息

Maven Central、npm 公共包、容器镜像地址、稳定发行标签及许可证链接暂为占位。当前前端包带有 `private: true`，不要把“可以本地安装”理解为“已经公开发布”。公开发布后，这一页将提供固定版本与校验摘要。

正式环境应固定你审核并构建的制品，不跟随可变分支或可变镜像自动升级。升级步骤见[升级与备份](../部署运维/升级与备份.md)。
