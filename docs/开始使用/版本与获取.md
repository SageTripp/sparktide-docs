# 版本、源码与安装方式

平台、后台 SDK 和前端 SDK 的首批公开制品使用固定版本 **0.1.0**。下载不要求私有源码仓库权限；HTTP `/v1` 和事件 `1.0` 是协议版本。

## 版本与下载

| 组件 | 固定版本 / 地址 | 使用环境 |
| --- | --- | --- |
| 底座 Jar | [sparktide-platform-0.1.0.jar](https://github.com/SageTripp/sparktide-docs/releases/download/v0.1.0/sparktide-platform-0.1.0.jar) | JDK 17；生产 PostgreSQL 17 |
| 底座镜像 | `ghcr.io/sagetripp/sparktide-platform:0.1.0` | Linux amd64；含中英文 Tesseract |
| Java 核心 | `dev.sparktide:sdk-java:0.1.0` | JDK 17 |
| Kotlin 扩展 | `dev.sparktide:sdk-kotlin:0.1.0` | JDK 17；复用 Java 核心 |
| Spring 集成 | `dev.sparktide:sdk-spring-boot-starter:0.1.0` | 宿主提供 Spring MVC Web 运行时 |
| 前端 SDK | [sparktide-frontend-sdk-0.1.0.tgz](https://github.com/SageTripp/sparktide-docs/releases/download/v0.1.0/sparktide-frontend-sdk-0.1.0.tgz) | ESM；Node.js 22；React 18–19 / Vue 3.5 |
| HTTP / 事件 | `/v1` / `1.0` | JSON、HTTP、SSE |

后台 SDK 的公开 Maven 仓库为 `https://sagetripp.github.io/sparktide-docs/maven/`。Gradle / Maven 安装及 Java / Kotlin 差异见[业务后台 SDK](../开发接入/业务后台SDK.md)；npm / pnpm / Yarn 安装见[前端 SDK](../开发接入/前端SDK.md)。这些渠道不依赖 Maven Central、npm 公共 registry 或 GitHub Packages 登录。

## 从零开始

下载[完整入门示例](../教程/准备环境.md)，按教程顺序运行底座 Jar、业务后台与前端。模型、业务工具、身份和配置声明通过 SDK 接入；无须先在管理平台建资源。

## 校验与版本固定

[0.1.0 发行页](https://github.com/SageTripp/sparktide-docs/releases/tag/v0.1.0)提供 SHA256 校验清单和各组件 manifest，记录源码提交与镜像 digest。Maven 离线镜像下载：[二进制 Maven ZIP](https://github.com/SageTripp/sparktide-docs/releases/download/v0.1.0/sparktide-backend-maven-0.1.0.zip)。公开 Maven 目录仅包含 Jar、POM 与校验值，不包含源码 Jar。

固定依赖版本与镜像 digest；已发布版本不覆盖，修复采用新版本。升级与数据库备份见[升级与备份](../部署运维/升级与备份.md)。

## 源码与授权

三个代码仓库继续私有，源码访问由维护者单独授权：

- [sparktide-platform](https://github.com/SageTripp/sparktide-platform)：底座与控制台。
- [sparktide-backend-sdk](https://github.com/SageTripp/sparktide-backend-sdk)：业务后台 SDK。
- [sparktide-frontend-sdk](https://github.com/SageTripp/sparktide-frontend-sdk)：前端聊天 SDK。

[sparktide-docs](https://github.com/SageTripp/sparktide-docs)公开维护文档、入门示例及制品分发。公开下载不代表源码开源；许可证与支持边界见[贡献与支持](../产品支持/贡献与支持.md)。
