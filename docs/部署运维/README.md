# 部署与运维

本区供底座和业务服务的部署维护人员使用。开发者第一次体验走[教程的环境步骤](../教程/准备环境.md)；首次健康检查成功后，回到[创建应用](../教程/创建应用.md)，不必转去控制台手工建整套资源。

| 阶段 / 需求 | 阅读顺序 | 完成标志 |
| --- | --- | --- |
| 首次生产部署 | [Docker 部署](Docker部署.md)或[独立部署](独立部署.md) → [环境变量](环境变量.md) → [HTTPS 与网关](HTTPS与网关.md) | 数据持久、授权正确、SSE 可用 |
| 需要多实例 | [集群部署](集群部署.md) | 共享 PostgreSQL，租约与任务协调验证通过 |
| 升级 / 迁移 / 备份 | [升级与备份](升级与备份.md) | 备份可恢复，兼容与回退路径明确 |
| 运行故障 | [监控与排障](监控与排障.md) → [可观测性与调用链](可观测性与调用链.md) | 用实际 Run 与调用证据定位问题 |
| 治理和生产核对 | [运行治理与执行核对](运行治理与执行核对.md) → [审计导出与留存](../开发接入/运维治理/审计查询导出与留存.md) | 输出受当前权限约束，结果有据可查 |

SDK 的模型 Key 仅保存引用，平台环境注入真实值。业务回调使用独立密钥并绑定 origin 和应用，不混用浏览器登录、应用管理和平台初始化凭据。
